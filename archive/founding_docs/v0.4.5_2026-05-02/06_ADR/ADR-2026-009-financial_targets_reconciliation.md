# ADR-2026-009: Финансовые целевые показатели — синхронизация

Дата: 2026-05-03
Статус: Accepted
Owner: Юра
Связанные документы: Context v0.4.5, CHANGELOG_v0.4.5, ADR-2026-008

---

## Контекст

В разных документах SPA v0.4.5 фигурируют три разных числа целевой доходности:
- Context раздел 1.2: «Net yield ≥ 9% годовых» (целевой коридор 9-11%)
- ADR-2026-008: «Net APY: 7.8% → 9.2%»
- CHANGELOG_v0.4.5: реалистичный прогноз 4.0% при $10K, 7.3% при $100K, 7.5% при $250K

Это создаёт неоднозначность при заполнении weekly reports («укладываемся ли мы в цель?»). Нужно зафиксировать единый набор цифр и значение каждой из них.

---

## Решение

Принять следующую иерархию финансовых целей:

### 1. Gross target APY (взвешенный по whitelist) = **7.4%**

Это математическое ожидание доходности портфеля до вычета газа.
Источник: weighted APY всех whitelisted протоколов с целевыми долями.
Используется в: Strategy Agent при оценке вариантов ребаланса.

### 2. Net APY targets (после всех издержек, по уровням капитала)

Это **реалистичные** ожидаемые показатели для разных размеров портфеля:

| Капитал | Net APY target | Чистый доход / год |
|---------|---------------|--------------------|
| $10K | 4.0% | $400 |
| $25K | 6.2% | $1 545 |
| $50K | 6.9% | $3 452 |
| $100K | 7.3% | $7 266 |
| $250K | 7.5% | $18 707 |

Источник расчёта: weighted gross APY 7.4% за вычетом газа ($25/op × 13 операций/год + final exit gas).

Используется в: weekly/monthly reports для оценки фактических показателей против target.

### 3. Aspirational target (≥9%)

Из критериев успеха проекта в Context 1.2.

**Переформулировано:** это **aspirational** показатель при масштабировании капитала **от $250K** в комбинации с одним из факторов:
- Снижение gas-cost через L2 deployments (Arbitrum, Base в Tier 1)
- Активация Layer 5 opportunistic стратегий (auto-compound vault даёт +0.4-0.8 п.п.)
- Благоприятный рыночный контекст (повышенные APY на Pendle PT в bull market)

Aspirational target **не является обязательным условием** для:
- Перевода документов из Draft в Frozen
- Запуска paper trading
- Перехода paper → live

Это долгосрочная амбиция, не критерий успеха paper trading.

---

## Объяснение числа 9.2% из ADR-008

Число 9.2% в ADR-008 было промежуточной оценкой при выборе варианта v0.5 → v0.4.5. Оно соответствовало:
- Gross weighted APY 9.8% (с предположением о более высоких APY в Yearn без учёта 15% performance fee)
- Без полного учёта gas-cost для разных размеров капитала
- Без учёта drag от Tier 2 при стрессовых периодах

После проверки реальных формул и комиссий Yearn V3 (15% performance fee включён в публикуемые APY на yearn.fi), реалистичная оценка скорректирована до 7.3-7.5% net при капитале $100K-$250K.

ADR-008 формально не отзывается, но числа в нём заменяются текущими (см. таблицу выше). Это исправление методологии, не изменение whitelist.

---

## Критерии успеха paper trading (обязательные, переформулированы)

Paper trading считается успешным при выполнении **всех** условий:

- Net APY ≥ **target по соответствующему уровню капитала** из таблицы выше (а не ≥9%)
- Drawdown ≤ 5% годовых
- ≤ 1 критический инцидент за 8 недель paper
- ≤ 10% времени в safe-mode
- Все weekly reports сформированы без пропусков
- Ноль нарушений Risk Policy и Mode Policy
