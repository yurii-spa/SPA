# ADR-2026-003: Provider stack для Data & Signals

Дата: 2026-05-02
Статус: Accepted
Owner: Юра
Связанные документы: Data & Signals v0.3 (раздел 4.4)

---

## Контекст

Data & Signals v0.3 раздел 4.4 содержит список кандидатов в provider stack, но требует ADR для финального выбора. Без конкретного stack реализация в Claude Code / Codex невозможна.

Требования к stack:
- минимум 2 независимых источника для каждого критичного слоя
- бюджет ориентир $50–150/месяц на старте
- free tier допустим, paid tier обязателен после 4 недель live
- все провайдеры должны иметь публичные API и историю работы ≥ 12 месяцев

---

## Решение

### Слой RPC (on-chain доступ)

| Роль | Провайдер | Тип | Причина |
|------|-----------|-----|---------|
| Primary | Alchemy | Платный (free tier для старта) | Надёжность, широкая поддержка, хорошая документация |
| Backup | Ankr | Freemium | Независимый провайдер, поддерживает Ethereum L1 |
| Emergency | публичный node (ethereum.org) | Бесплатный | Только для аварийного fallback |

Переход на paid tier Alchemy: после 4 недель live или при превышении rate limits.

### Слой Oracle (цены)

| Роль | Провайдер | Причина |
|------|-----------|---------|
| Primary | Chainlink price feeds (on-chain) | Бесплатный, top-tier, используется протоколами |
| Confirmation | Pyth Network (on-chain) | Независимый, push-based |
| Cross-check | RedStone | Третий независимый источник для верификации |

Все три oracle читаются on-chain — без дополнительных API-затрат.

### Слой данных протоколов (TVL, APY, метаданные)

| Роль | Провайдер | Тип | Причина |
|------|-----------|-----|---------|
| Primary | DeFiLlama API | Бесплатный | Стандарт индустрии, покрывает все три протокола |
| Backup | прямые on-chain reads | Бесплатный | RPC calls к контрактам протоколов |

### Слой индексации (исторические данные, события)

| Роль | Провайдер | Тип | Причина |
|------|-----------|-----|---------|
| Primary | The Graph (subgraphs для Aave, Compound) | Freemium | Стандарт для DeFi аналитики |
| Backup | Etherscan API | Freemium | tx история, event logs |

### Слой security feeds (ранние предупреждения)

| Роль | Провайдер | Тип | Причина |
|------|-----------|-----|---------|
| Primary | BlockSec X/Twitter feed | Бесплатный | Быстрые алерты по эксплойтам |
| Secondary | PeckShield X/Twitter feed | Бесплатный | Независимый источник |
| Tertiary | Cyvers | Бесплатный | Дополнительное покрытие |

*Примечание: security feeds — off-chain signals. Согласно Data & Signals v0.3 раздел 4.3 и Agent Architecture v0.3 раздел 6.1, они не являются прямым триггером автоматических действий. Только через preprocessing и structured data.*

### Слой compliance (санкционные проверки)

| Роль | Провайдер | Тип | Причина |
|------|-----------|-----|---------|
| Primary | OFAC SDN list (прямой download) | Бесплатный | Официальный источник |
| Secondary | EU restrictive measures list | Бесплатный | Официальный источник |

Обновление: ежедневно автоматически. При росте до Fund этапа — рассмотреть Chainalysis или TRM Labs.

### Исторические данные (для paper trading)

| Роль | Провайдер | Тип |
|------|-----------|-----|
| TVL/APY история | DeFiLlama API (бесплатно) | Бесплатный |
| On-chain события | The Graph subgraphs | Freemium |
| Gas история | Etherscan gas tracker API | Freemium |

## Ожидаемый бюджет

| Период | Расходы/месяц | Статус |
|--------|---------------|--------|
| Paper trading (8 недель) | ~$0–20 | Free tiers достаточно |
| First 4 недели live | ~$0–20 | Free tiers |
| После 4 недель live | ~$50–100 | Paid Alchemy + The Graph |
| При росте капитала | ~$100–200 | Возможно Chainalysis |

---

## Альтернативы, которые рассматривались

- **Infura вместо Alchemy** — оба равнозначны. Alchemy выбран из-за более подробной документации и лучшего developer experience.
- **QuickNode** — хорошая альтернатива, но дороже для старта.
- **Собственный node** — избыточно для Self-Capital этапа; рассмотреть при Fund этапе.

---

## Последствия

- Data & Signals v0.3 раздел 4.4 считается заполненным
- Реализация в Claude Code / Codex может начинаться с конкретными endpoint'ами
- Следующий пересмотр stack: после 4 недель live или при изменении доступности провайдеров
