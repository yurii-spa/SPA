Документ используется:
- для ручной валидации;
- для ИИ-агентов (Strategy Agent);
- для paper trading и симуляций;
- для объяснения логики участникам проекта.

## 11. Kill Criteria (условия закрытия стратегии)

Стратегия переводится в статус Retired при выполнении одного или нескольких условий **с числовыми порогами**:

- **Net yield < 0** в течение **8 недель** подряд;
- **Net yield < половины ожидаемого** в течение **12 недель** подряд;
- **Drawdown стратегии > Y%** за квартал (Y задаётся в 5.2);
- **>3 safe-mode переходов** за квартал без понятного объяснения;
- **>5 ручных вмешательств Owner** за месяц;
- **Tier протокола** снизился до Tier 3 без plan по восстановлению;
- **Регуляторный риск** материализовался;
- найдена **более эффективная альтернатива** по аналогичному риск-профилю с zero replacement cost.

Решение о закрытии стратегии принимает Owner через ADR.

Закрытие стратегии **не означает выход из позиции немедленно** — это означает:
- запрет новых входов;
- плановый выход в течение 30 дней;
- финальный post-mortem с выводами.
