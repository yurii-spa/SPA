## Кого искать

`stusd` · `wusdm` · `notional_v3` · `sdai` · `scrvusd` · `frax` · `pendle_pt_susde`

Пока протокол не наблюдается, капитал в него разместить **нельзя** — это не «недооптимизированный

## Что уже проверено (не повторять)

Поиск по DeFiLlama делался 2026-08-05. Совпадения находились почти для всех, и **пять оказались
чужими инструментами** — подключить их значило бы ранжировать капитал по числу от другого актива:

| ключ | что нашлось | почему отклонено |
|---|---|---|
| `sdai` | `sparklend/SDAI` $44 562 @ 0 % | пылевой пул, не настоящий sDAI |
| `scrvusd` | `REUSD-SCRVUSD` | LP-пара, не сам актив |
| `frax` | тот же пул, что `sfrax` | два ключа → один пул = скрытая концентрация |
| `pendle_pt_susde` | — | нужного рынка в фиде нет |
| `stusd`, `wusdm`, `notional_v3` | — | в фиде отсутствуют вовсе |

Запрет «два ключа на один пул» закреплён тестом `test_no_two_keys_share_a_pool`.

## Где искать дальше (по убыванию шансов)

1. **Собственные API протоколов** — Angle (stusd), Mountain (wusdm), Notional (notional_v3)
   публикуют ставки у себя; DeFiLlama их просто не индексирует.
2. **On-chain чтение** — для ERC-4626 хранилищ ставку можно вывести из `convertToAssets()` на
   двух отметках времени. Тем же способом, что уже работает для GSM: кворум ≥2 независимых RPC,
   отказ при расхождении.
3. **Другой агрегатор** — но с той же дисциплиной: закреплённая личность пула, иначе провенанс
   не годится для гейта (ADR-064).

## Обязательные требования к любому найденному источнику

- **Закреплённая личность.** Пул опознаётся по устойчивому идентификатору, а не по «похоже
  подходит»: TVL-провенанс `live` ставится только на закреплённое совпадение.
- **Один пул — один ключ.** Два протокола, указывающие на один пул, дают удвоенную экспозицию,
  которой кэп не видит.
- **Тот самый инструмент.** `sdai` — это sDAI, а не любой пул со строкой SDAI в символе.
- **Отказ при недоступности.** Нет наблюдения ⇒ `None`, никаких подстановок (ADR-063).

## Как понять, что готово

По каждому из семи: либо появился наблюдаемый `live_apy` с закреплённым источником, либо записан
разбор «публичного источника не существует» — тогда вопрос возвращается владельцу уже с фактами.

## РЕЗУЛЬТАТ ПОИСКА 2026-08-05 (широкий скан 15 639 пулов DeFiLlama)

Двое из семи закрыты параллельной сессией — закреплены по UUID, инструменты проверены верными:
`sdai` → Ethereum/sky-lending/SDAI $210M @ 1.25 %, `scrvusd` → Ethereum/crvusd/SCRVUSD $18.7M @ 1.10 %.

Отдельно: наблюдаемые 1.25 % у `sdai` спорят с заметкой реестра «real DSR rate 3.6–4.75 %».
Проверено — **устарела заметка, а не наблюдение**: 1.25 % это сегодняшний `apyBase`, и косвенно
подтверждается тем, что `sky_susds` даёт 3.52 % (Sky уводит пользователей из DAI в USDS более
высокой ставкой). Заметку в реестре надо поправить, иначе она будет спорить с данными.

### Остальные пять — разбор по каждому

**`stusd`, `wusdm`, `notional_v3` — в DeFiLlama отсутствуют полностью.** Не «нашлось не то», а
ноль совпадений из 15 639 пулов по всем комбинациям проекта и символа. Публичного агрегированного
источника нет; остаются собственные API протоколов (Angle, Mountain, Notional) либо on-chain
чтение ERC-4626 (`convertToAssets()` на двух отметках) с тем же кворумом ≥2 RPC, что уже работает
для GSM.

**`frax` — отдельного доходного инструмента не существует.** Единственный доходный пул Frax это
SFRAX ($65.1M @ 1.25 %), уже закреплённый за ключом `sfrax`. Остальные 29 пулов проекта — LP-пары
под ~0 %. Ключ `frax` в реестре дублирует `sfrax`; закрепить их на один пул запрещено
(`test_no_two_keys_share_a_pool`) — два ключа на одном пуле дают удвоенную экспозицию, которой кэп
не видит. **Это кандидат не на поиск источника, а на удаление из реестра** — возвращаю вопрос
владельцу с фактом.

**`pendle_pt_susde` — источник ЕСТЬ, но закреплять его статически нельзя.** Две причины:

1. *Один пул отдаётся дважды с разными инструментами.* Различает поле `poolMeta`:
   `"For buying PT-sUSDe-13AUG2026"` — это PT (фиксированная ставка, что и моделирует адаптер),
   `"For LP | Maturity 13AUG2026"` — LP-позиция с другим риском. При одинаковом TVL $8.24M их APY
   **4.26 % против 12.39 %** (на Monad — 4.11 % против 12.39 %). Правило «побеждает крупнейший TVL»
   выбрало бы между ними монеткой. Ещё одно подтверждение, зачем нужно закрепление по UUID.
2. *Инструмент датирован.* PT гасится **13AUG2026 — через 8 дней**. Статическое закрепление
   гарантированно протухнет: после погашения пул исчезает, наблюдение прекращается (fail-CLOSED,
   безопасно), но фид будет выглядеть рабочим ровно до того дня. Это не источник, а источник
   с истекающим сроком.

**Что нужно для Pendle PT:** логика перекладки по сроку (whitelist это уже признаёт — у
`pendle-pt-usdc-arbitrum` стоит `"special": "fixed_rate"`, `"note": "requires maturity-aware
logic"`). Закрепление должно указывать на *рынок*, а не на конкретный выпуск, и переезжать на
следующий срок при погашении. Отдельная задача; статический пин заводить НЕ стал.
