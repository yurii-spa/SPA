Продолжение **ADR-107** (решение владельца 1, 21.08 09:40Z). Первый файл снят, остальные — здесь.

## Что уже сделано

`data/kill_switch_active.json` снят с отслеживания и удалён на `origin`. Причина — измеренная:
если прод реально встанет по аварии (`active: true`), а дерево кто-то восстановит из резерва или
откатит деплой, версия из git молча затрёт живую остановку, и торговля пойдёт дальше при
сработавшем выключателе. Сторож: `spa_core/tests/test_halt_state_survives_tree_restore.py`.

## Что осталось

Правило `.gitignore` (`data/*.json`, `data/**/*.json`) на уже попавшие внутрь файлы не
действует, и таких накопилось **295** рабочих файлов состояния — среди них текущие позиции,
лимиты риска и торговый шлюз. Все они точно так же откатываются к старому снимку при
восстановлении дерева.

## Что делать

**Пачкой снимать НЕЛЬЗЯ.** Часть путей — осознанный owner-gated канон (CLAUDE.md: «`data/` —
runtime-only в .gitignore, **часть owner-gated tracked**»), и снятие такого пути сломает
проверки, которые на него опираются (например, сверку с каноном на CI).

Порядок:

1. Составить полный список 295 путей (`git ls-files data/`), разложить по КЛАССАМ:
   живое состояние · трек и его доказательства · канон, читаемый CI · артефакты отчётов ·
   заведомый мусор.
2. По каждому классу ответить на два вопроса: **что откатится при восстановлении дерева** и
   **чем это грозит** — так же, как это сделано для файла остановки (там ответ был «молчаливое
   возобновление торговли»).
3. Найти читателей каждого класса (`grep` по имени файла) — снятие пути, который читает CI или
   сторож, превратит зелёный в вечно красный.
4. Отдельной карточкой владельцу — только те классы, где снятие меняет поведение системы или
   ломает существующего читателя. Остальное снимать по классам, по одному классу за заход,
   каждый — с тестом «этот путь не отслеживается».

## Acceptance criteria

- Есть документ с разбором по классам (не список из 295 строк, а классы с ценой отката).
- Ни одного пути не снято без названного читателя (или доказанного отсутствия читателей).
- Инструмент доставки — `scripts/github_delete.py` (пушер удалять не умеет, ADR-107).
- **Живой трек `data/equity_curve_daily.json` НЕ трогать** — он git-tracked осознанно
  (решение владельца, память `owner-decisions-resolved`); он попадёт в класс «трогать нельзя».

## Границы

Не money-path по коду, но задевает доставку и канон. Ничего не снимать «за компанию»: цена
ошибки — молча ослепший сторож.
