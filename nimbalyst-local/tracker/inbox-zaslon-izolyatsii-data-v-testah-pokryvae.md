Заслон герметичности тестов покрывает **1 модуль из 209**, а обещает покрывать все.

`tests/conftest.py::_isolate_data_dir` — autouse-фикстура, которая, по собственному
описанию, «points the runtime data-dir env (SPA_DATA_DIR) at a per-test tmp dir so any
code that resolves its data dir via the standard mechanism never reads/writes the live
repo-root data/». Механизм рабочий. Проблема в слове «standard»: замер цикла #361 —

* модулей рантайма (не тесты), которые берут каталог состояния литералом
  `_REPO_ROOT / "data"`: **209**;
* из них консультируются с `SPA_DATA_DIR`: **1** (`spa_core/paper_trading/_cycle_io.py`);
* адаптеров в этом списке: **16 из 16 мимо заслона**;
* всего модулей рантайма, знающих слово `SPA_DATA_DIR`: **14**.

Значит, у 208 модулей вердикт теста определяет **живой файл хоста**, а не код.

**Доказанная жертва (уже починена этим же циклом).**
`spa_core/tests/test_allocator_evidence_gate.py::test_sky_susds_gsm_gate_is_consulted`
проверял `_adapter_class_gate("spark_susds")` односторонним `assert allowed is False`.
Гейт создаёт настоящий адаптер (`cls()`), тот берёт `_DEFAULT_DATA_DIR = _REPO_ROOT/"data"`
мимо `SPA_DATA_DIR` и читает живой `data/adapter_status.json`. Замер:

| состояние хоста | `_adapter_class_gate("spark_susds")` | старый тест |
|---|---|---|
| канон `origin/main` (наблюдения GSM нет) | `(False, 'gsm_not_confirmed')` | зелёный |
| боевое дерево (GSM 48 ч наблюдён on-chain, ADR-065) | `(True, None)` | **КРАСНЫЙ** |

Один и тот же код, два вердикта — решает файл данных. Шапка этого тест-файла при этом
обещает «Offline + deterministic … no dependence on the live repo's `data/`»; для этого
теста обещание было ложным. Починка (цикл #361): состояние стало **входом** — тест сам
пишет блок `spark_susds` и подменяет `_DEFAULT_DATA_DIR`, проверка двусторонняя (6 случаев:
подтверждённый GSM на пороге и выше ⇒ `(True, None)`; ниже порога / не наблюдён / без
отметки времени / отметка протухла ⇒ `(False, 'gsm_not_confirmed')`). Обратный контроль
измерен: старый тест на подтверждённом GSM краснеет, новый зелен ПРИ ОБОИХ состояниях хоста.

**Почему это класс, а не один тест.** Ровно тот же разрыв («время/состояние — окружение,
а не вход») уже описан в `.claude/rules/deployment.md` про даты. Здесь то же самое про
данные, и цена выше: тест-сторож денежного гейта менял вердикт от того, в каком дереве его
запустили.
