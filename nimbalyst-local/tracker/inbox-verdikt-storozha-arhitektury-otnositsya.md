## Замер 2026-09-01 (цикл #447) — тот же дефект, конкретный случай, и громче звучит ЛОЖНАЯ строка

Обязательный шаг 0-офис по `data/architecture_conformance.json` (вердикт `WARN`,
critical 0, warn 2) напечатал про ОДИН предмет две строки, которые противоречат друг другу:

```
[WARN] com.spa.gas_price_agent работает, но plist не персистентен
       (repo:launchd/com.spa.gas_price_agent.plist) — не переживёт ребут
[WARN] манифест ↔ факты: com.spa.gas_price_agent:
       plist_source 'repo:launchd/…' → 'launch_agents'; reboot_safe False → True
```

**Перемерено на хосте (read-only, ничего не трогал):**

```
ls -l ~/Library/LaunchAgents/com.spa.gas_price_agent.plist
  -rw-r--r--  1022  Aug 31 21:53           ← персистентная копия ЕСТЬ
launchctl print gui/501/com.spa.gas_price_agent | grep 'path ='
  path = /Users/yuriikulieshov/Library/LaunchAgents/com.spa.gas_price_agent.plist
```

Загруженный агент читается из персистентного пути. **Первая строка неверна: ребут он
переживёт.** Верна вторая — устарел `plist_source` в `architecture/manifest.json`.

**Почему это стоит отдельного упоминания в этой карточке, а не новой.** Предмет тот же
(вердикт относится к манифесту, которого уже нет), но цена вскрылась новая: обе строки
выводит ОДИН сторож в ОДНОМ отчёте, и **громче звучит ложная** — «не переживёт ребут»
читается как авария и зовёт трогать прод-дерево, тогда как честная строка про расхождение
манифеста стоит рядом и выглядит служебной. Обязательный шаг цикла, который через раз
показывает ложную аварию, учит сессии его пролистывать — это и есть его отказ.

**Почему не починил этим циклом.** `architecture/manifest.json` в прод-дереве лежит
**изменённым и незакоммиченным** (`git status` на старте сессии: `M architecture/manifest.json`),
автор правки не объявлен ни одним announce. Курация манифеста доезжает до прода только
через `origin` (ADR-152 + замер про синхронизацию), и правка поверх чужой незакоммиченной
работы её затёрла бы молча. Трогать не стал намеренно — это ровно та авария, ради которой
заведена эта карточка.

**Что делать (не решение, предложение):** сверять `plist_source`/`reboot_safe` с ФАКТОМ
до печати первой строки — если факты уже дают `reboot_safe True`, строка «не переживёт
ребут» не должна произноситься вовсе; остаётся одна честная — «манифест отстал».
