**Как найдено (цикл #37).** Задача цикла была про `cycle_health_monitor`, и первым же шагом
вскрылось, что весь его файл тестов (88 тестов) **молча скипался**: в `except ImportError`
выставлялся **file-level** `pytestmark = pytest.mark.skip(reason="… API refactored — tests need
rewrite for new interface")`. Импорт падал потому, что блок был перенаправлен на модуль, который
этих символов не экспортирует. Побочный эффект: вместе с тестами мёртвого модуля выключился
41 тест **живого** модуля, лежавший в том же файле и импортировавшийся нормально. Починено,
запушено (64 passed на чистом `origin/main`, было 0 passed / 88 skipped).

**Это не единичный случай — это класс.** Скан всего дерева тестов на file-level skip:

**Итого 404 теста над ЖИВЫМ кодом** висят за формулировкой «API отрефакторен», причём три файла
несут её слово в слово — признак разовой массовой правки, а не разбора каждого случая. В цикле #37
ровно эта формулировка оказалась **неверной для обоих модулей, которые она называла**. Считать её
проверенной нельзя ни для одного из оставшихся файлов.

**Почему это важно.** Инвариант #16: молча ослаблять/выключать тесты запрещено; красный тест —
сигнал. Скип с неверной причиной хуже красного теста: он не виден в CI, не попадает в счётчик
падений и создаёт впечатление покрытия там, где его нет. `pendle_pt_adapter` — не абстрактный
модуль, он в `ADAPTER_REGISTRY` (см. `.claude/rules/adapters.md`).
