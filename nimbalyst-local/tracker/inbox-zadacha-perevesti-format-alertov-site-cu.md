## Сделано (автономный цикл, 2026-07-29)

Алерты владельцу переведены на простой русский **в единственной точке**, через которую
идут все Tier-1 уведомления (`spa_core/telegram/push_policy._format_message`), плюс
отдельно — Site Custodian (`scripts/site_freshness_monitor.py::_alert`).

- новый модуль `spa_core/telegram/humanize.py` (детерминированный, stdlib, без LLM);
- контракт: нераспознанная строка проходит **вербатим** (перевод не может «съесть» проблему),
  числа/пороги/имена агентов переносятся из исходной строки, ничего не выдумывается,
  сбой перевода отдаёт исходный текст (алерт обязан дойти);
- логика гейта (whitelist / edge-trigger / дневной лимит / held-scoping) НЕ тронута;
- +63 регресс-теста (`spa_core/tests/test_telegram_humanize.py`), включая побайтовую проверку
  «все числа примера владельца дожили до перевода».
