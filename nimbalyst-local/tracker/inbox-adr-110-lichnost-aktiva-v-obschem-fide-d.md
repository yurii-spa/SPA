Реализация **ADR-110** (решение владельца A, 21.08 09:36Z). Решение записано, код — здесь.

## Что делать

Перенести проверку **личности актива** в общий фид `spa_core/adapters/defillama_feed.py`
(`get_pool`, стр. 134–151), чтобы оба производителя доходности опознавали пул одинаково.
Эталон уже есть: `spa_core/bee/defillama_feed.py:286` (+ тест `test_feed_hint_asset_identity.py`).

Сегодня общий фид сверяет три строки (`project` / `symbol` / `chain`) и берёт пул с бо́льшим
TVL. «Побеждает больший» — не признак правильности. Замер на записи скана 09–10.08 без сети:
на ОДНОМ наборе пулов проверяющий источник даёт **3.29 %** (настоящий USDC), общий фид —
**4.79 %** (токен `0xD4fa…D23E`, который тоже зовётся «USDC», но им не является). Подделка
платит БОЛЬШЕ — значит дефект выглядит как удача и толкает решение в сторону входа.

## 🔒 УСЛОВИЕ ДОСТАВКИ, поставленное САМИМ владельцем

В карточке-решении дословно: «по A — готовлю изменение фида в изолированном дереве, прогоняю
`pre_cutover_gate`, **показываю тебе список протоколов, которые останутся без числа, и только
потом доставляю**».

**Пока список не показан владельцу — правка на `origin` НЕ уезжает.** Это часть принятого
решения, а не осторожность агента. Порядок: реализовать в изолированном дереве → прогнать
`pre_cutover_gate` → замерить список «остались без живого числа» → показать карточкой
владельцу → и только после подтверждения доставлять.

## Acceptance criteria

1. Один и тот же набор пулов, поданный обоим источникам, даёт ОДНО число по `aave_v3`;
   это проверяется тестом (имя из карточки: `spa_core/tests/test_apy_one_definition.py`).
2. Пул с чужим адресом базового актива (тот самый `0xD4fa…D23E`) НЕ опознаётся как наш —
   положительный контроль на записи скана, без сети.
3. Протокол без объявленного адреса актива получает честное «не наблюдали», а не число
   неизвестного происхождения.
4. Замерен и приложен СПИСОК протоколов, теряющих живое число, с количеством.
5. `pre_cutover_gate` пройден; полный прогон тестов зелёный.

## Чего НЕ делать

**Вариант B не ставить.** Агент рекомендовал его как страховку «до A», владелец выбрал только A.
Поставить B молча — исполнить невыбранное решение. Если A задерживается, вопрос про страховку
задаётся отдельной карточкой.
