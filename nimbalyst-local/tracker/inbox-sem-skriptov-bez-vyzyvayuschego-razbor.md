## Что случилось

Цикл #228 закрыл три слепоты храповика неподключённых скриптов (карточка
`inbox-hrapovik-schitaet-upominanie-v-dokstring`). Сканер перестал считать проводкой
докстринг, самоупоминание однофамильца и подстрочную коллизию — и **семь скриптов,
которые всё это время числились подключёнными, оказались без единого вызывающего**:

| скрипт | что держало его «подключённым» | что это такое |
|---|---|---|
| `audit_tier_c_wiring_feasibility` | докстринг сгенерированного им же `spa_core/analytics/_protocol_key_coverage.py` | разовый аудит-генератор (замер 06.08) |
| `reap_stale_worktrees` | докстринг + шаг 0г `docs/ORCHESTRATOR_PROTOCOL.md` | уборщик мёртвых worktree'ов (#230) |
| `run_stress_tests` | докстринг `spa_core/stress/stress_engine.py` | CLI стресс-движка MP-112 |
| `smoke_test_flagship` | докстринг `scripts/smoke.py` («в отличие от …») | тяжёлый end-to-end смоук |
| `day30_review` | самоупоминание `spa_core/riskwire/day30_review.py` | тонкая обёртка над ЖИВЫМ модулем WS1.3 |
| `ots_anchor` | самоупоминание `spa_core/audit/ots_anchor.py` | CLI внешнего якорения (ADR-YL-010) |
| `perf_budget` | подстрока внутри `dfb_perf_budget.py` | perf-гейт money-path (WS-6.5) |

**Это НЕ брак измерения.** Проверено сплошным поиском по `*.sh`, `*.plist`, `*.yml`,
`*.json` и по всем импортам: ни plist'а, ни обёртки, ни CI-шага, ни импорта — ноль
у всех семи. Храповик `test_unwired_scripts_ratchet` краснеет ПРАВДУ.

## Почему нельзя просто дописать их в базу

`unwired_scripts_baseline.json` может только уменьшаться — это записано в самом
храповике, в правиле `.claude/rules/deployment.md` и в задании цикла. Дописать семь
имён, чтобы стало зелено, значит превратить базу в мусорный список и обнулить смысл
первой половины храповика. Прецедент: #192 оставил проверку красной ОСОЗНАННО ровно
по этой причине.

## Что сделать — по каждому скрипту отдельно, решение своё

Три возможных исхода у каждого, и у каждого своя цена:

1. **Подключить по-настоящему** (plist / обёртка / шаг цикла / CI) — годится там, где
   скрипт обязан выполняться сам. Кандидат номер один: **`ots_anchor`**. ADR-YL-010
   пишет дословно: «Daily agent runs `python3 scripts/ots_anchor.py both` — wired in the
   deploy checklist (owner-gated; **not auto-deployed** by this branch)». То есть ADR
   обещал ежедневное якорение, а агента нет **с 03.07**. Это находка ровно того класса,
   ради которого храповик и заведён, и она пролежала скрытой полтора месяца.
2. **Списать** (как #227 поступил с `daily_paper_report`) — если функция схлопнута в
   другое место и запуск скрипта ВРЕДЕН. Проверять по трём независимым следам, не по
   одному.
3. **Признать отдельным измеренным классом** — но только с замером цены правила, как
   делали с реестром R&D (#214). Два кандидата на класс просматриваются, и оба требуют
   решения владельца, а не правки строки:
   - **«шаг протокола»**: `reap_stale_worktrees` и `adr_number` названы командами в
     `docs/ORCHESTRATOR_PROTOCOL.md` и исполняются каждым циклом. Цена правила замерена:
     **2 скрипта из 61**, то есть класс узкий. Возражение против: строку в протокол
     дописать легче, чем заслужить запись в реестре R&D измерением;
   - **«тонкая обёртка над живым модулем»**: `day30_review`, `ots_anchor` — тело
     скрипта это `import` + делегирование в модуль, который сам вызывается из цикла.
     Мёртв тут только вход, а не логика — в отличие от семи аварий, породивших храповик
     (kill-switch, erc4626, `gsm_hours`, генератор changelog: там не исполнялась ЛОГИКА).

**Ни один из двух классов циклом #228 не заведён намеренно:** заводить второе исключение
тем же циклом, что снимает три слепоты, — это big-bang, который стоп-правило проекта
запрещает. Сперва решение, потом код.

## Границы

Только тестовый слой + возможная установка агента (owner-gated). RiskPolicy, kill-switch,
живой трек и сайт не затрагиваются.

## Как понять, что готово

По каждому из семи есть решение с доказательством (подключён / списан / отнесён к классу
с замеренной ценой правила); база храповика НЕ выросла ни на одно имя; храповик зелёный
не потому, что ему соврали.
