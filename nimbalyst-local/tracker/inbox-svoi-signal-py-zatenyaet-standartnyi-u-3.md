## Что измерено

Каталог `spa_core/monitoring/` содержит свой модуль **`signal.py`** (RTMR,
ADR-053). Запуск любого скрипта из этого каталога **ПО ПУТИ**
(`python3 spa_core/monitoring/<что-то>.py` — именно так зовут launchd и цикл)
делает `sys.path[0]` каталогом скрипта, и тогда `import signal` внутри
стандартного `subprocess` достаёт НАШ модуль вместо стандартного.

Пока всё идёт хорошо, этого не видно ничем. Ломается **ИМЕННО путь отказа**:

```
subprocess.run(..., timeout=N)   # срок вышел
 → process.kill()
 → signal.SIGKILL
 → AttributeError: module 'signal' has no attribute 'SIGKILL'
```

То есть вместо третьего исхода «не измерено — прогон не уложился в срок»
прибор **падает целиком**.

**Замер 2026-09-19 (цикл #638), воспроизведён с контролем в обе стороны:**
тот же скрипт из `spa_core/monitoring/` падает, он же из корня репозитория
даёт чистый `TimeoutExpired`. Авария не гипотетическая — на ней умер прогон
зонда ADR-420 на 52-й строке из 100, журнал не записан.

**Население:** в каталоге **136** модулей с `__main__`; из них **30** шлют
`subprocess` со сроком, то есть несут живой фитиль. Среди них —
`deployment_acceptance.py`, `deployment_drift_monitor.py`,
`agent_health_monitor.py`, `card_delivery.py`, `copy_independence_probe.py`.

## Что уже сделано (и чего НЕ сделано)

Починен **ОДИН** вход — `spa_core/monitoring/vacuous_guard_probe.py`
(раззатенение выше всех ввозов, ADR-420). Он чинился потому, что без него
нельзя было получить сам замер заказа G44; остальные 29 **названы, а не
починены прицепом** — у переименования `signal.py` свой радиус и свой предмет.

⚠️ Ловушка, стоившая одной итерации: сравнивать каталоги надо по
**`realpath`**, а не по `abspath`. С Python 3.11 `sys.path[0]` есть
РАЗЫМЕНОВАННЫЙ каталог скрипта, а `abspath` ссылок не разыменовывает — на
macOS (`/tmp` → `/private/tmp`) версия с `abspath` молча не чинила ничего.
Поймано собственным контролем, а не рассуждением.

## Что сделать

Выбрать ОДНО из двух и довести до конца, не смешивая:

1. **Переименовать `spa_core/monitoring/signal.py`** (например в
   `risk_signal.py`) и провести ввозы. Лечит класс целиком и навсегда;
   радиус — все импортёры RTMR, нужен свой прогон.
2. **Раззатенение у каждого из 30 входов** + храповик, краснеющий на новый
   вход без него. Лечит повод, класс остаётся: завтра в каталоге появится
   ещё один модуль-однофамилец stdlib.

Рекомендация агента — вариант 1: вариант 2 по построению есть «список лечит
поводы», против которого написан сам заказ G44.

## Как понять, что готово

Сцена из `spa_core/tests/test_vacuous_guard_probe.py`
(`TheTimeoutPathSurvivesAStdlibShadow`) остаётся зелёной, И новый сторож
показывает **0** модулей каталога, у которых срок `subprocess` недостижим.
Обратная сторона обязательна: сторож обязан краснеть на воспроизведённой
аварии.

## Чего НЕ делать

Не ослаблять сроки и не убирать `timeout=` «чтобы не падало» — предмет
карточки ровно в том, что путь отказа обязан быть достижим.

## Откуда взялось

ADR-420, цикл #638. Авария собственного прогона зонда, не рассуждение.
