## Что измерено (цикл #191, 2026-08-10)

Починка разбора вариантов вернула кнопки двум карточкам (остановка прода, тир `morpho_steakhouse`),
но в очереди ожидающих ответа осталось **восемь без кнопок**. Замер по `data/telegram_owner_decisions.json`
после починки:

| карточка | почему без кнопок |
|---|---|
| `own-rnd-killswitch-rearm-policy-missing` | ДВА решения в одной карточке (А1/А2/А3 и Б1/Б2) + номер из двух знаков |
| `owner-decision-posle-strahovki-dengi-ostayutsya-sirotam` | multiselect по замыслу (`allows_multiple`) — НЕ дефект |
| `owner-decision-tablichka-chestnosti-ne-doezzhaet-do-sai` | то же, multiselect |
| `owner-decision-reshenie-po-alertu-spa-7-day-checkpoint` | секция из 3 строк, вариантов нет вовсе |
| `owner-decision-kritichnaya-nahodka-petli-com-spa-{telegr,digest,tier1,weekly}` | секция из 2 строк, вариантов нет вовсе |
| `own-flat-probe` | файла карточки нет (проба) |

Итог: из восьми **один** — наш случай (карточку надо РАЗДЕЛИТЬ, как разделили карточку об
остановке), два — законный multiselect, пять — карточки-поручения без выбора.

## Что сделать

1. Разделить `own-rnd-killswitch-rearm-policy-missing` на две карточки (решение А — политика
   возврата после жёсткой остановки; решение Б — что означает мягкая ступень) и переотправить.
2. Для карточек-поручений без выбора (`kritichnaya-nahodka-petli-*`, `7-day-checkpoint`) решить,
   нужна ли им кнопка «сделано/принято» — сейчас владелец не может ответить на них НИКАК, кроме
   слов; пять таких висят с 08.08 без ответа.
3. Проверить, не даёт ли `allows_multiple` ложных срабатываний: у `posle-strahovki` перечень
   `Вариант 1/2/3` разбирается, а multiselect гасит кнопки — возможно, фраза-триггер стоит
   в пояснении, а не в самом вопросе.

## Как понять, что готово

Среди ожидающих ответа карточек нет ни одной, у которой варианты В КАРТОЧКЕ ЕСТЬ, а кнопок нет.
Проверка — тем же замером по журналу отправок.

## Почему это отдельная карточка

Правило «одна карточка — одно решение» родилось в этом же цикле; остаток очереди по нему ещё не
приведён, а молча оставить его нельзя — именно на такой тишине система простояла остановленной.
