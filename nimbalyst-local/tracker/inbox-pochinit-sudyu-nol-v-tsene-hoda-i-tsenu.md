## Что сделать

В `spa_core/paper_trading/shadow_trigger_eval.py` заменить

```python

```

на

```python

```

Записанный ноль тогда означает «ход измерен и бесплатен», а допущение
`ASSUMED_COST_BPS_OF_TURNOVER` = 15 bps остаётся только для «цены не записали».

Порядок объявлен владельцем в самой карточке и не сокращается:

1. правка отдельным ADR с прогоном `pre_cutover_gate`;
2. тест, который **краснеет при возврате старой ветки** (положительный контроль, не украшение);
3. **перемер всех чисел ADR-388…390** — они считались при старом условии, и часть может сдвинуться.
   Перемерять ИСХОДОМ (прогон приборов), а не пересчётом в уме;
4. приёмка по исходу, названная владельцем: `data/swap_existence_price.json` перестаёт печатать
   находку `zero_price_is_read_as_absent_price`, то есть лучший счёт при нулевой цене становится
   **не хуже**, чем при цене в один цент.

(`capital_usd`, все листы `current_positions` / `target_positions`). Владелец отвечал на карточку
про одну ветку; остальные 19 идут отдельной карточкой владельцу и без его ответа не трогаются.

Это money-path, предмет №1 ADR-285. Разрешение на ЭТУ правку — получено.
