## ЗАКРЫТО циклом #221 (2026-08-13) — причина названа и починена

**Причина (замер, не догадка):** `stat -f %m` в `scripts/agent_template.sh` — форма BSD. У
GNU-coreutils `-f` означает «статус ФАЙЛОВОЙ СИСТЕМЫ» и формата не берёт, поэтому `%m` уезжает как
ИМЯ ФАЙЛА, а на stdout приходит текстовый блок вместо числа. Страховка `|| echo 0` этого не ловит:
для существующего файла блок печатается. Мусор попадает в `$(( ))`, `age` остаётся неприсвоенным,
и `set -u` роняет ОБЁРТКУ. Отсюда `assert 1 == 0` ровно в двух тестах — тех, где метка существует.

**Сверх карточки.** Код возврата этой смерти зависит от версии bash: CI (bash 5) — rc=1, наш прод
(bash **3.2.57**) — **rc=0, лог пуст, python не запускался**. То есть на проде та же поломка
выглядит как успешно отработавший агент. Сегодня прод спасает лишь то, что `stat` в его PATH
резолвится в BSD-версию; первый же GNU-`stat` в `miniconda3/bin` (ПЕРВЫЙ каталог PATH обёртки)
тихо погасил бы флот с кодом успеха. Воспроизведено копией прод-обёртки с заглушкой в PATH.

**Починено (в скрипте, не в тесте — как и просила карточка):** переносимое `stamp_mtime()`
(обе формы + проверка, что вышло число; не число ⇒ синк, а не падение, и с записью
`CODE_SYNC stamp_age_unknown` в лог) + вызов секции синка **в подоболочке**, чтобы любой будущий
обрыв внутри неё не мог стать отказом агента (условие владельца стало свойством файла, а не
дисциплины автора).

**Приёмка:** +4 теста, гоняющие GNU-`stat` с macOS через тест-хук `SPA_AGENT_STAT`; 4 мутации
краснят поимённо; полный предписанный прогон зелёный. Ни один тест не ослаблен и не выключен.

Второй красный воркфлоу (`SPA CI`, 17 падений) — ДРУГАЯ причина, вынесен в отдельную карточку
`inbox-spa-ci-krasnyi-12-progonov-17-testov-sud`.
