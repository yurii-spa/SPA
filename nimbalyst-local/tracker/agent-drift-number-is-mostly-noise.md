## Четыре `launchd/*.plist` разобраны — тоже не дефект (2026-08-10)

Git показывал их как **удалённые** относительно origin, хотя файлы лежат на диске и все
четыре агента работают в флоте.

Причина: они **не отслеживаются локальным индексом** (`git status` даёт `??`). Существуют на
диске и на origin, но локальный git о них не знает — а `git diff origin/main` смотрит только
на отслеживаемые файлы, поэтому и рисует «удалено».

**Это прямое следствие рабочего процесса, а не поломка:** пуши уходят в origin через API и
локального индекса не касаются (записано в памяти проекта: «local git drifts, truth =
origin»). Файл создали на машине, отправили в origin — локально он так и остался
неотслеживаемым.

Попутно в том же каталоге: `com.spa.morning_digest.plist` помечен удалённым (агент выведен
в `attic/` 08.08 — ожидаемо), `com.spa.novel_edge_rnd.plist` изменён.
