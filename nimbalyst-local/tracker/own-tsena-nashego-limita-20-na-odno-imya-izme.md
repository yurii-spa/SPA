# Цена нашего лимита «не больше 20 % на одно имя» измерена: поднимать его незачем, он стоит ровно в лучшей точке

## Что случилось и почему это важно

Ты 8 августа попросил перестать перебирать признаки и честно измерить главную ручку агрессивного
тира — саму концентрацию: сколько доходности стоит наш лимит «не больше 20 % капитала на одно
имя» и что будет с просадкой, если поднять его до 25 % или 30 %. Замер сделан на той же реальной
истории десяти книг (852 дня, 2024-03-06…2026-07-05), менялся ровно один параметр — потолок.

**Ответ отрицательный, и это лучший из возможных исходов: менять ничего не надо.** В той
раскладке, которую исследование само называет своим лидером, лимит вообще не срабатывает —
фактически самая крупная позиция там 17 %, до 20 % она не доходит, то есть лимит стоит ноль.
А там, где он срабатывает, поднятие потолка добавляет доходность и **ровно в той же пропорции
ухудшает просадку**, так что результат «на единицу риска» не растёт, а падает.

Таблица (доходность после издержек / просадка / доходность на единицу риска), потолок 20 % против
25 % и 30 % — просадка стоит рядом с доходностью, иначе цифра в этом семействе бессмысленна:

| сколько книг выключено | потолок 20 % | потолок 25 % | потолок 30 % |
|---|---|---|---|
| 4 | 33.6 % / −3.4 % / **10.6** | 35.0 % / −4.3 % / 9.1 | 35.0 % / −4.3 % / 9.1 |
| **5** | **34.8 % / −3.4 % / 10.8 ← лучшая точка всей таблицы** | 40.7 % / −4.3 % / 10.3 | 41.7 % / −4.4 % / 10.2 |
| 6 | 32.2 % / −3.6 % / 9.5 | 40.1 % / −4.5 % / 9.5 | 45.1 % / −5.1 % / 9.4 |
| 7 | 28.0 % / −3.6 % / 8.2 | 34.5 % / −4.5 % / 8.1 | 41.3 % / −5.4 % / 8.1 |
| 8 | 23.6 % / −3.7 % / 6.6 | 28.7 % / −4.6 % / 6.5 | 34.0 % / −5.5 % / 6.4 |

Отдельно про ту прибавку «+5…+8 %», которая была в исходной постановке вопроса: она существует
только там, где на одно имя приходится **100 % капитала** — то есть восемь книг из десяти
выключены, а все деньги стоят в одной. Это не портфель, и такой вариант не доставляем ни по
нашему лимиту, ни по здравому смыслу.

## Что от тебя нужно

Ничего менять не требуется — нужно только подтвердить, что ты вопрос закрытым считаешь.

- **Вариант A (рекомендую).** Считать вопрос закрытым: лимит 20 % остаётся как есть, отдельное
  решение про изменение порогов не нужно, задача из реестра снимается. Почему рекомендую: замер
  показал, что 20 % — не налог на доходность, а её максимум на единицу риска, и поднимать потолок
  означало бы платить просадкой за цифру в отчёте.
- **Вариант B.** Хочешь увидеть тот же замер на втором признаке отбора книг (сейчас основная
  таблица посчитана для одного) — тогда это отдельная итерация исследования, без изменений
  в проде.

## Как понять, что готово

Ты выбрал A или B; при A карточка уходит в `ingested`, и вопрос порога 20 % больше не поднимается
без нового решения.
