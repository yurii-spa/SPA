## Что случилось и почему это важно

Спасибо — новый ключ GitHub работает: 26 ноября в 09:43 по Мадриду вся накопленная
за простой работа уехала на сервер одним стеком (27 коммитов, циклы #1238…#1258).
Простой доставки продлился **36,2 часа** и закончен.

Но у нового ключа **не хватает одного разрешения**, и это уже измерено живыми
запросами: читать он может всё (код возврата 200), код отправлять может, а вот
**запускать проверочный прогон тестов (GitHub Actions) — не может**: сервер отвечает
`403 Forbidden`. У прежнего ключа это разрешение было, и агент каждый цикл заказывал
прогон сам.

Чем это плохо на практике: после доставки агент больше не может сказать серверу
«проверь вот этот коммит». Приходится ждать прогона по расписанию (каждые ~6 часов),
то есть вердикт о свежей работе приходит с задержкой, а иногда не приходит вовсе —
расписанный прогон берёт не тот коммит.

## Что от тебя нужно

Один шаг, в настройках GitHub (Settings → Developer settings → Personal access tokens
→ Fine-grained tokens → твой токен `GITHUB_PAT_SPA` → Edit):

**шаг 1.** В разделе «Repository permissions» у репозитория `yurii-spa/SPA` поставить
разрешению **Actions** значение **Read and write** (сейчас, судя по ответу сервера,
оно либо «Read-only», либо отсутствует).

**шаг 2.** Сохранить. Значение самого ключа при этом НЕ меняется — перекладывать его
в Связку ключей заново не нужно, ничего больше делать не требуется.

Остальные разрешения уже верны и их трогать не надо: `Contents` = Read and write (код
уехал) и `Workflows` = Read and write (если его нет — поставить тоже, он нужен, когда
меняются сами файлы в `.github/workflows/`).

## Как понять, что готово

Агент повторит замер одной командой и ждёт `204` вместо `403`:

```
python3 scripts/ci_control_verdict.py --order-run <полная sha>
```

## Что будет после

Агент снова заказывает контрольный прогон сразу после каждой доставки и в том же цикле
докладывает вердикт: что покраснело от доставки, а что было красным до неё. Без этого
разрешения он может только читать результат чужого прогона — и честно говорить «вердикт
о моём коммите НЕ ИЗМЕРЕН».
