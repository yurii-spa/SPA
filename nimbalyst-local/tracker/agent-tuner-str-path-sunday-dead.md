**Что найдено (цикл #31).** `spa_core/paper_trading/cycle_runner.py:1998` вызывает
`run_allocation_tuner(data_dir=_eff_data_dir)`, где `_eff_data_dir = str(_eff_dir)` (строка 1935), а
`run_allocation_tuner` объявляет `data_dir: Optional[Path]` и делает `ddir / "…json"`.

**Воспроизведено (не гипотеза):**

```
>>> run_allocation_tuner(data_dir=tempfile.mkdtemp())   # ровно то, что передаёт cycle_runner
TypeError: unsupported operand type(s) for /: 'str' and 'str'
```

Ветка выполняется только по воскресеньям (`datetime.now().weekday() == 6`) и не в `--dry-run`, а
вызов завёрнут в `try/except` → **исключение съедается**, `data/tuner_suggestion.json` не пишется.
То есть тюнер MP-207, судя по всему, не отработал НИ РАЗУ — и никто этого не видел.

**Как нашли:** шаг `mypy` в CI-Lite. Гейт был мёртв (падал раньше, на опечатке `SpaError`), поэтому
ошибка типов никем не читалась. После фикса опечатки (цикл #31) шаг mypy начнёт выполняться и
покажет **4 ошибки**: 2 в `spa_core/allocator/allocator.py` (`no attribute "config"`,
`no-untyped-def`), 2 в `cycle_runner.py` (`no-any-return` на 1784, этот `arg-type` на 1998).
