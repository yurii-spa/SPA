## Что это за проект («сигналы»)

**Non-custodial advisory / signals** — SPA отдаёт РЕКОМЕНДАЦИИ по доходности, но НИКОГДА не касается
чужих денег. Подписчик получает сигнал (какой протокол · APY · тир · risk-категория · рекомендуемая
доля · обоснование) и исполняет сам своим кошельком. Мы — «мозг», исполнение и хранение — на стороне
пользователя.

**Почему привлекательно:**
- **Нет кастодиана** → нет хранения ключей, нет custody-риска, нет тяжёлого KYC/AML управления
  чужим капиталом.
- **Монетизируется без лицензии на управление активами** (подписка / тиры доступа / API).
- **Переиспользует то, что УЖЕ построено:** весь аналитический контур, RiskPolicy, тир-курация,
  APY-ранжирование, evidence-логи — сигналы это их побочный продукт.
- **Ров «проверь нас»** прямо работает на сигнальный продукт: проверяемая история качества сигналов.

**Почему НЕ следующий шаг paper-теста:**
- Не доказывает исполнение (мы не исполняем) — не снимает ни один из 7 недоказанных пунктов.
- Не решает кастодиан/ключи (by design).
- Это ОТДЕЛЬНЫЙ продукт со своей разработкой, дистрибуцией и, возможно, своим комплаенсом.
