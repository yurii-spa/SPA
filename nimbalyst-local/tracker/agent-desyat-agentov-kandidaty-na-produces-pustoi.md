# Кандидаты на пустой контракт — подтвердить у автора

После заполнения объявлений (28.08) без `PRODUCES` осталось 10 агентов. У всех у них по коду
не видно записи ни одного артефакта, а докстринги описывают их как **службы и отправителей**,
а не производителей файлов:

| агент | что делает по докстрингу |
|---|---|
| `com.spa.apiserver` | FastAPI app factory, отдаёт данные по HTTP |
| `com.spa.familyfund` | FastAPI app factory (кабинет инвестора) |
| `com.spa.dashboard_watcher` | опрашивает живой API, шлёт тревоги в Телеграм |
| `com.spa.digest_weekly` | недельный дайджест в Телеграм (пишет лишь сторожевой dot-файл) |
| `com.spa.tier1_digest` | недельный Tier-1 дайджест в Телеграм |
| `com.spa.checkpoint-7day` | валидация после 7 дней, шлёт результат |
| `com.spa.aggressive_lab` | CLI/тик лаборатории |
| `com.spa.strategy_lab_paper` | CLI живого paper-сервиса |
| `com.spa.cmo_editorial` | черновой редакционный прогон |
| `com.spa.monthly_statement` | выписка за период — путь ШАБЛОННЫЙ (`data/statements/<период>.json`) |

## Почему НЕ объявил их сам

`PRODUCES = ()` — это **ответ** «ничего не произвожу», а не пустота. Он закрывает вопрос, и
закрывает его от имени автора. Объявить его по своей догадке — ошибка того же класса, что
выдумать путь: выглядит как знание, проверить нельзя. Правило этой работы (ADR-158): не удалось
установить — оставить без объявления, а не додумать.

Для `monthly_statement` отдельно: путь шаблонный, и объявлять шаблон как артефакт нельзя —
сроку годности не к чему прикрепиться.

## Что сделать

По каждому подтвердить у автора/владельца одно из:

1. `PRODUCES = ()` — служба, файлов не производит. Тогда по ADR-154 возникает следующий вопрос:
   **чем измеряется, что она работает?** У службы это не свежесть файла, а доступность порта или
   факт отправки — и это надо назвать, иначе агент останется без метрики качества навсегда.
2. конкретный список путей — если запись всё же есть, но делается ниже по импортам.

## Как понять, что готово

`python3 -m spa_core.monitoring.artifact_contract` не показывает ни одного `undeclared`.
