## Что сделано

`spa_core/telegram/humanize.py` — новая таблица `_DETAIL_RULES` + `_humanize_detail()`:
переводится **хвост** строки `[SEV] CODE: detail` для всех 10 форматов, которые умеет писать
`scripts/site_freshness_monitor.py` (STALE_SNAPSHOT · STALE_API · MISSING_ASOF ×2 ·
SITE_BEHIND_SNAPSHOT ×2 · SNAPSHOT_BEHIND_API · OVERSTATED_METRIC · UNAVAILABLE ·
VERIFIER_PIN_MISMATCH). Плюс два кода (`SITE_BEHIND_SNAPSHOT`, `SNAPSHOT_BEHIND_API`)
переформулированы — их пояснение уехало в скобки, иначе в строке получалось два тире подряд.

Контракт модуля НЕ ослаблен:
- числа/даты/пороги/URL берутся из match-групп — ничего не выдумывается;
- формата нет в таблице → хвост проходит **вербатим** (лучше по-английски, чем никак);
- сбой правила → исходный текст целиком (алерт обязан дойти).
