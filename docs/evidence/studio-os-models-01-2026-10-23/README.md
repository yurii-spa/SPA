## Чего это НЕ доказывает

- Что пакет переносится в ДРУГОГО поставщика (ChatGPT, локальную модель): обе сессии — Claude. Перенос между
  поставщиками — следующий шаг вместе с контрактом провайдера (инкремент 2), не выполнен.
- Что любой хендовер разберётся: темы ищутся по ключевым словам заголовков; не нашлось — UNKNOWN, не догадка.
- Что пакет свеж: он о моменте сборки (`generated_at`, `inputs_sha256`); после нового коммита собирается заново.
- Роутер моделей, контракт провайдера, второй адаптер, учёт ресурсов — НЕ сделаны.
