## Срок — временная сцена без модели (`spa_core/tests/test_model_roles_deadline.py`)

Поддельный «claude» порождает внука в НОВОЙ сессии и зависает; рядом процесс, запущенный тестом и к запуску
не принадлежащий. Через адаптер: исход `timeout`, помощник `rc=124` («владение закрыто»), внук завершён,
посторонний процесс жив. Положительный контроль: прежний `subprocess.run(timeout=3)` внука НЕ завершает.
Нормальный ответ проходит через помощник без искажений. Мутация «по умолчанию мимо помощника» — красная.
