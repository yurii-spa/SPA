## Decision

Add **one guard** inside `_render_sherlock`, placed after the `schema`/`sherlock` check and before the counters: if `doc.get("generated_at") is None`, render a screen with the unchanged head, no counters, no blockers, no "«Всего фактов» не показываю" line, a single body line "Сводка Sherlock: {NOT_MEASURED} (лента фабрики исследований не содержит прогона)", and the existing `freshness_line(None, now, stale, src)`. BROKEN keeps precedence (it is already checked earlier), which matches the cockpit's `integrity != "BROKEN" and generated_at is None` conjunct. Why: `generated_at is None` is exactly B-11's "nothing recorded" criterion in the shared reader, so both surfaces decide the same question from the same field; the change is confined to one presentation function and cannot alter the reader, the cockpit, or Company Truth; and the cockpit↔bot rule is then *enforced* by extending the existing same-truth test to an empty-ledger input rather than by duplicated prose.

Rejected:
- Make `research_factory.read.latest` itself drop/flag the `sherlock` block when there is no run — changes the shared contract for all consumers beyond B-11's accepted scope; blast radius unjustified for a P3.
- Have the bot render from `mission_control._research_universe_section` / `company_truth.capital_sherlock` — makes the bot depend on the cockpit build layer and re-touches verified code.
- Extract a shared `read.no_run(doc)` predicate used by both cockpit and bot — architecturally tidier but re-touches B-11-verified `mission_control.py` for a P3; the same-truth test holds the rule instead. Record the seam in the backlog.
- Leave the counters and rely on the freshness line alone — the counters are zeros presented as a measurement; that is the defect.
