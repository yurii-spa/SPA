# STUDIO-OS-MODELS-01 · инкремент 2 — контракт провайдера и конфигурация ролей (2026-10-24)

Код: коммит **`c60ad6d6a`** ветки `integ/studio-os-next-01-stab`. Решение владельца — ADR-OWN-2026-10-23. **Не роутер**:
назначения ролей в `architecture/model_roles.json` равны `null`, вызывающие не переключены, провайдер называется явно.

## Что сделано

| требование ARB | где |
|---|---|
| роли `architect`/`worker` отдельно от провайдера/модели | `architecture/model_roles.json` (`roles` ≠ `providers`) |
| провайдер — явной конфигурацией | `execute(provider_id=…)` либо `assignments[role]`; оба `null` ⇒ `refused` |
| адаптер Claude и тестовый адаптер — один контракт | `adapters.claude_cli` (существующий `claude -p`, `--tools ""`, `--strict-mcp-config`, `--output-format json`) и `adapters.fixture` получают один `render_prompt(req)`, возвращают `AdapterOutput` |
| неизвестный/неподходящий провайдер — явный отказ | неизвестный · не квалифицирован · без возможностей · контекст больше лимита (без усечения) · объявил права/инструменты · нет адаптера ⇒ `refused`, другой адаптер не зовётся |
| таймауты и повторы ограничены | срок попытки — роль; попыток ≤ min(роль, 3); повтор только `timeout`/`error`; `quota`/`malformed` — без повтора |
| смена провайдера не расширяет полномочий | `permissions`/`tools` берутся только у роли; провайдер с `permissions`/`tools` отказан |
| время и сведения об использовании | `elapsed_s`, `attempts`, `attempt_log`; токены/стоимость — только сообщённые CLI; `quota_remaining` и прочее — `UNKNOWN`; стоимость CLI ≠ списание подписки |

Контроли: `spa_core/tests/test_model_roles_contract.py` (25 тестов; мутации 6/6 убиты).

Расхождение по п. 2 — показательное, а не дефект: ответ фикстуры ЗАРАНЕЕ записан (при HEAD = проверенному коду он

КОНТРАКТ (вход, форму, отказы, учёт), а не качество ответа, и вторым провайдером не является.

Реальных вызовов Claude в этом инкременте — **2** (первый на рабочем дереве до правки учёта кэш-токенов, второй —

## Чего это НЕ делает

Производственная маршрутизация не включена; существующие вызывающие (`memory/answer.py`, `dev_agents/architect.py`)
не переведены на контракт; второго НАСТОЯЩЕГО провайдера нет; квалификация провайдера по качеству не измерена;
отмена (cancellation) — только по сроку subprocess.
