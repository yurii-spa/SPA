  RPC) → `loop_book.valuation` → аварийный выход/ликвидация в `supervise`. **PYUSD не измеряется** (принят $1).
  **Депег-стоп RiskPolicy к циклу НЕ подключён:** ни один вызов `check_portfolio_health` не передаёт `stablecoin_prices`
  (`engine.py:802,896`, `trim_admissibility.py:477`) — проверка пропускается по умолчанию (`policy.py:750-752`).
* **Стрессы воспроизводимы** формулами `loop_book.py` из последней измеренной оценки; это модель, не наблюдение.
* **Вердикт: `INCOMPLETE_EVIDENCE` сохраняется** — учёт сверен, но (а) долг 116 % NAV в PYUSD без цены, (б) опубликованная
  ставка считается с неверной точки, (в) плавающие ноги без рыночной оценки, (г) 4,3 % прогонов без замера, когда
  стопы петли бездействуют.
