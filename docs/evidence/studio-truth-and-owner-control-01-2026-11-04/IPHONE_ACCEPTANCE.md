# Проверка с iPhone после релиза (ручная — не автотест)

**Пульт https://mc.earn-defi.com** (вход Cloudflare Access):
1. «Главное сейчас» — первой строкой «Инвестиционный движок заблокирован: earn_defi…»; в следующем шаге — вопросы к вам и «ещё N без темы разбирает ассистент» (на 04.11: 0 вопросов с темой, 2 без темы; в Телеграме «Мои решения» показывает те же 2).
2. «Существенные проблемы» — первый пункт объясняет KC-1: дата 19.09, причина, «ежедневная проверка… новых срабатываний не дала», «Снимает: владелец».
3. Нет вопросов про диск («Диск снова съел…», «123 ГиБ»).
4. «Защита» → «Версия системы»: «Работает код <sha>… доверенный корень S2 одобрил 4cb68535…, флот не переключён».
5. «Защита» → «Что реализовано, но не работает»: decision_loop выключен, aggregate off, E6.6 подготовлена, S5 — стенд.
6. «Деньги» → торговые движки: лента сигналов (BUY/SELL с ценой виртуального исполнения), пять кандидатов.
7. Тревоги: «cycle_failed … с тех пор не подтверждалось».

**SPA Monitor** (`/start`):
8. «Здоровье» не пишет «✅ система OK» при предупреждениях; строка «Движки ⛔ earn_defi: INCIDENT KC-1 с 2026-09-19».
9. Go-Live: «критерии пройдены · live НЕ разрешён — решения владельца нет»; «обновлено» с датой.
10. В течение 3 суток после релиза earn-defi нет повторов «system mode INCIDENT».

**Studio Bridge**:
11. Отчёт → «Продукт»: «Forward-кандидаты (5 из 5…)».
12. Кнопки разделов меняют то же сообщение; внизу «🏛 Домой».
