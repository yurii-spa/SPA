## 📋 Активные задачи

_Только ОТКРЫТОЕ. Закрытое живёт в `docs/journal/` — перечислять его здесь и есть та хроника, которой файл дорос до 591 026 символов._

- **[ЖДЁТ ВЛАДЕЛЬЦА] BTC-движок не помещается под стоп-кран** (`own-btc-dvizhok-ne-vlezaet-pod-stop-kran`):
  −20…−25 % NAV против HARD_KILL −10 %. Бэктест сохранён замером (`research/btc_cycle/`, ADR-102), движок
  НЕ строится, функция остаётся L2. Работа неполна: чемпион `backtest.py` и логика загрузки — в чате владельца.

  за 30 дней ACT не было ни разу, `week_turnover_ok` отказал на 17 из 17 существенных дней, а `net_bps`
  считается только по оценённому ACT (замер #487, ADR-228). Решение — `owner-decision-sovetnik-po-perekladke-deneg-ne-smozhet`.
- **[ЖДЁТ ВЛАДЕЛЬЦА] Вторая половина порога TVL** (#168): у порога ОДНО определение
  (`spa_core/risk/tvl_floor.py`), но гейт не знает про ADR-064 — money-path.
- **[ЖДЁТ ВЛАДЕЛЬЦА] Balanced: книга не пуста, а ФАНТОМНА** (#208): `equity > 0` при `positions_count = 0`
  в каждой строке — `hy_cycle` начисляет среднюю ставку полосы на всю сумму. Карточки
  `owner-decision-sbalansirovannyi-tir-na-saite-idet-paper` + `inbox-sbalansirovannyi-trek-nol-profinansirova`.
- **[ИДЁТ] Три храповика красны на `origin/main` — это настоящие сигналы, не шум** (замер #958):
  `step_time_drift` (читателя нет — провести или вывести решением) · `worker_axis_census` и две R&D-идеи

## 🗂️ Последние решения (одной строкой → ADR)

- **2026-10-28 · ADR-841 (цикл #961)** — вердикта CI на `main` не было ЧЕТЫРЕ прогона подряд, и дерево
  тут ни при чём: `pip install pytest` без `==` берёт версию у календаря, 9.2.0 убивал раннер сигналом
  shutdown на СБОРЕ за ~40 с, сводки не было ВОВСЕ под словом `failure` (9.1.1 тот же набор довёл до
  «54 failed, 120055 passed … 5:57:21»). Шесть строк в пяти воркфлоу пиннуты, храповик на `==`.
  Зелени это НЕ обещает: возвращена ВОЗМОЖНОСТЬ судить. Предмет «память сбора» назван, не закрыт.
- **2026-10-28 · ADR-840 (цикл #961, заказ G839 п. 2)** — колонка «Заголовок» реестра решений
  приведена к ЗАГОЛОВКУ: им стала строка `H1` файла решения (`adr_number.py titles --write`), 675 строк
  из 691, отказов 0, цена чтения **1 574 973 → 136 610** символов. Реестр сохранён дословно
  (`journal/INDEX-archive-2026-10-28.md`): проза строки в файле решения НЕ лежала — найдена у 96 из 675.
  Побочно: у длины колонки было ДВА разбора, наивный занижал её на 18 строках (ADR-831: 163 против 2 089).
- **2026-10-28 · ADR-838 (цикл #960)** — предел цены чтения стоял на ОДНОМ файле набора: реестр решений
  стоял 52× потолка соседа. Храповик на колонку + потолки `CLAUDE.md`/`SYSTEM_MAP`/брифинга; состояние убрано ADR-840.
- **2026-10-27 · ADR-837 (цикл #959)** — храповик `STATE.md` меряет ЧИСЛО СТРОК, а предел введён за ЦЕНУ
  ЧТЕНИЯ: 42 коммита «150 строк» при росте 523 684 → 591 026 символов. Теперь меряются ещё символы и строка.
- **2026-10-27 · ADR-836 (решения ВЛАДЕЛЬЦА)** — 16 ответов за одну сессию, очередь `needs-owner` 18 → 0; пороги RiskPolicy не меняются.
- **2026-10-27 · ADR-835 (цикл #958)** — путь тест-файла проводкой не является: таблица весов CI объявила «подключёнными» пять сторожей по строке с путём их же теста.
- **2026-10-27 · ADR-834** — карточки решений закрываются агентом по записи ответа владельца (инв. #14 цел).
- **2026-10-27 · ADR-833** — отметка `generated_at` у снимка `/api/dfb/pools` обязательна: без неё строки не отдаются.
- **2026-10-27 · ADR-832** — условие лицензии на данные решается при первом реальном долларе (вариант владельца).
- **2026-10-27 · ADR-830 + ADR-831** — строка реестра судится по ФОРМЕ, а не по числу чёрточек; реестр приведён целиком (186 → 0).
