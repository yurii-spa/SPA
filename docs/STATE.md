Остаток — ПРИЧИНА 1: раскладка фиксирована спредом, оптимум есть ЛП на каждом подмножестве (свой симплекс, только stdlib); money-path, решение владельца. **Мерить ПОСЛЕ починки двери цены** (`inbox-dver-tseny-otdaet-podporogovuyu-delt`): пока подпороговая дельта бесплатна, любой оптимизатор ищет её, а не оптимум.
2. **Потолок `max_protocols` объявлен, а у двери КНИГИ читателя нет** (`inbox-potolok-chisla-pozitsii-obyavlen-a-u-dve`; замер #973): `RiskConfig.max_protocols` = 8 (ALLOC-002) читают аллокатор и `policy_enforcer`, `check_portfolio_health` — нет. Урезанная интерполяцией книга даёт больше позиций, чем ОБА конца отрезка, на **51** записи из 103 и переваливает за 8 на **1**. Чинить не молча: порог money-path-соседний, проба — с контролем в обе стороны.
3. **Ответы владельца 27.10 без исполнителя — по одному, поимённо с замером** (`inbox-vosemnadtsat-otvetov-vladeltsa-27-10-isp`; перенесено из G847–G854, НЕ тронуто). Из 18 (замер #967): исполнено 2 · нечего 6 · ждёт владельца 1 · ждёт ПРАВА у ключа 1 · НЕ исполнено 6 · НЕ измерен 1. Из шести ЧЕТЫРЕ money-path: тиры `morpho_steakhouse`/`pendle` · оптимум против «ничего не делать» · N = 3 дня устойчивости выгоды · качели за 14 дней. Каждому — своя проба и свой ADR.
4. **Привязка читателя к блоку — по ДОРОГЕ значения, а не по имени ключа** (`inbox-privyazka-chitatelya-k-bloku-po-doroge-z`; ADR-856). #974 закрыл измеримую половину G855 п. 4: блоков, публикующих ДВА населения, **18**, у **8** число отсутствия не читает НИКТО (`inbox-vosem-blokov-publikuyut-chislo-otsutstvi`; у трёх ключ один ⇒ ОДНА правка на три места), эталон различает. Вторая половина НЕ ИЗМЕРЕНА ЗНАЧЕНИЕМ: обе наивные привязки проведены и обе неверны — по ключу отсутствия исход НЕДОСТИЖИМ по построению (печатался бы ноль), по узнаваемым ключам 864 пары / 67 проверяемо ложных. Якорь «АДДИТИВНО + ВПЕРЁД» даёт 2 поля; семантический даёт ещё 9 и НЕ перемерен.
5. **Диск: скорость мерит СТОРОЖ, а не живая сессия** (ADR-862, #979): `gb_per_hour` + `minutes_to_full`, 4 исхода (инв. #17), голос в `overall` только на повышение — при 18 ГБ/ч CRITICAL наступает при 18 ГБ, на час раньше черты 15. Живая проверка: `falling 16.97 GB/h — full in 24.4 min`. Премиса порогов ADR-551 ложна ×14.3, пороги НЕ подняты намеренно. **Причина у владельца** (`owner-decision-disk-snova-sel-odin-zhurnal-agenta-9-82`), усечение по кругу — на сессии (за #979 шесть раз). Остаток: БАЙТЫ мусора и срок доступности (`inbox-baity-prosrochennogo-musora-i-srok-ego-d`) — 381 стенд = 11.00 ГБ, `bytes: null`.
7. **У ОТВЕТА на голосовое задание нет канала к владельцу — он попросил СЕДЬМОЙ раз во время цикла, который отвечал** (`inbox-otvet-na-golosovoe-zadanie-vladeltsa-ne`; ADR-860). Дашборд проверен ДВАЖДЫ (#966 28.10, #977 29.10, числа сошлись), оба ответа легли В ФАЙЛ: у `owner-decision` канал есть (`notify` + квитанция), у голосового задания нет вовсе. Ось повтора закрыла видимость для АГЕНТА; это — видимость ОТВЕТА для ВЛАДЕЛЬЦА. Остатки: `nack` на вопрос-уточнение читается как отмена ПРЕДМЕТА; 10 чужих красных храповика приёмки — часть носители БЕЗ записи `carried_to`, перемерять поимённо.
