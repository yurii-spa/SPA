## 🗂️ Последние решения (одной строкой → ADR)

- **2026-11-15/16 · ADR-1020…1031 (циклы #1158–#1170, G1012…G1019)** — находка офиса несёт РЕДАКЦИЮ прибора (из **133** прежняя редакция у **18**). **1022/1023:** перемер стал прибором — из 8 измеримых НЕ воспроизвёлся НИ ОДИН; причина разведена третьим прогоном: РЕДАКЦИЯ 1 · ДАННЫЕ 1 · **ОБЕ 6**. **1025:** входы НЕ называют **16 из 16** производителей офиса, РЫЧАГ ПУСТ. **1026/1027:** проводка упоминанием СИРОТЫ, **352 из 2729 корней мертвы**. **1028:** «достижим» ≠ «ЗОВЁТ» — 5 из 213. **1029:** «упомянут» ≠ «ПРИПИСАН» — 44,4 % из 6011. **1030:** вердикт был свойством номера ОС. **1031:** род раннера вычитал из вилки ЖИВЫЕ дефекты — 7 из 19 суть ОДНА дверь, база **19 → 11**.
- **2026-11-16/17 · ADR-1032…1039 (циклы #1171–#1178, G1020…G1027)** — **1032:** вердикт был свойством ширины `ps`: членов **5**. **1033:** шаг 1д шесть циклов давал код 1 на одном составе — рост состава теперь МЕНЯЕТ код. **1034:** ключ события зависел от `$TMPDIR`. **1035:** `#` в прозе внутри ОТКРЫТОЙ строки оболочки стирал **66 %** места объявления шагов цикла. **1036:** санитар трассы чистил объект, который заменяет ПЛОСКИЙ хук `unittest`, — не работал НИ ОДНОГО ДНЯ. **1037:** население ТОГО класса **1 из 23**. **1038:** прибор #1176 приехал БЕЗ двери песочницы и покраснил двух сторожей в ДЕНЬ доставки; дельта CI ПО ИМЕНАМ 67→65 = ушло 4, ПРИШЛО 2.
- **2026-11-17 · ADR-1040…1044 (циклы #1179–#1183, G1028–G1031 + автономный)** — **1040:** мест объявления **ДВА**, членов **0**. **1041:** пробы «ЖИВОЕ дерево + ИЗВЕСТНЫЙ член» нет у **46 из 90** (ВЕРХНЯЯ граница). **1042:** 46 разбиты ЗАСЕВОМ: слепоты 0, **26** стóят одной строки против **20** полной пробы. **1043:** из 26 законны **20**, у **3** ВСЕ зовы одноразовы (строка = ЛОЖНОЕ усиление); у ЗАЧТЁННЫХ проб **5 из 44** приборов живого дерева не касаются. **1044:** из вилки дефектов CI взяты 4 имени — у **3** дефект У МЕРКИ, не в коде: «hack» домена читался маркером (15 ложных из 16), сторож utcnow обвинял ДОКСТРОКУ; починены производители, набор −3 имени.
- **2026-11-17 · ADR-1045 (цикл #1184, G1033 п. 2)** — ещё **8** имён вилки = **2** предмета: у `python_git_ref_provenance` четыре имени = ОДИН дефект (производные контроли НАЗЫВАЮТ предпосылку), у `subscript_silencer` четыре = ОДИН таймаут `setUpClass` в CI при 16 passed/57 с на своём дереве.
