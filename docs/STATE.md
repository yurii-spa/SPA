## 🗂️ Последние решения (одной строкой → ADR)

  население замера больше единицы: ADR-853 вывел «меньше ног ⇒ дешевле» из механизма и честно оставил РАССУЖДЕНИЕМ. Прибор
  (`paper_trading/trim_shape.py`, блок `shadow_trigger_eval.trim_shape_census`, два читателя) сравнил формы при ОДНОМ потолке,
  ОДНОМ движении кэша и ОДНОЙ модели: на **103 предложениях / 66 датах** подмножество по спреду не хуже НИ ПО ОДНОЙ оси
  (дороже 0, выигрыш ниже 0, окупаемость хуже 0), медиана окупаемости 150.5 → 65.2 дн., в горизонт 30 дн. укладываются 9 → 19.
