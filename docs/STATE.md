Направление отказа названо: лишняя цель для гейта ПОКРЫТИЯ безобидна, а пропущенный вызов для гейта ИСКЛЮЧЕНИЙ — fail-OPEN, поэтому у каждого сужения стоит обратный контроль. `strip_inline_comment` переехал в ОБЩИЙ разбор (копии больше нет — он звался только разбором окружения, оттого общий разбор целей и продолжал читать комментарий). +10 тестов, 7 мутаций, каждая красит свою цель. **Рецидив урока #304 у себя:** свой контроль на `python3 -m pip install --quiet pytest` был зелен под ВСЕМИ семью (там `pytest` — последний токен, целей нет и при сломанном разборе) — усилен утверждением о числе распознанных вызовов. **Намеренно правлен ЧУЖОЙ тест (инв. #16, обоснование в теле и в журнале W34):** контроль #304 закреплял `len(steps) == 2`, то есть ровно ту половину дефекта (шаг установки всё равно числился шагом с pytest, целью становился `pyyaml`) — проверка УСИЛЕНА, не снята, и краснеет на состоянии до починки.
