## 2. Внешние потоки — их нет (доказано по каждому бару)

Для всех 106 баров после начала выполнено одновременно:
- открытие = закрытию предыдущего засчитанного бара (допуск 1 цент) — 106 из 106;
- закрытие − открытие = доход дня − издержки дня (допуск 2 цента) — 106 из 106.

Остатка, который мог бы быть вводом/выводом денег, нет ни в одном баре. Значит:
**метод — отношение NAV** (`NAV_конца / NAV_начала − 1`). Без потоков доходность, взвешенная по
времени (TWR), и доходность, взвешенная по деньгам (MWR), — одно и то же число; витрина несёт обе
отдельно. Если поток когда-нибудь появится, функция сама переключится на TWR по подпериодам
(оценка — открытие бара после потока) и посчитает MWR (Modified Dietz) отдельно — это покрыто тестом.

## 6. Длительность и соглашение о днях

**ACT/365 Fixed по датам оценки:** `дней = дата конца − дата начала = 108`. Бар — оценка на конец дня,
помеченная датой, и начисляет ровно один день дохода; время запуска цикла (оно сдвигалось с 17:04 на
06:00–07:51 UTC) записано рядом, но длительностью не служит. Дни без бара остаются внутри периода:
дохода за них не начислено, поэтому такое соглашение может только ЗАНИЗИТЬ годовой эквивалент, но не
завысить. Прежний расчёт брал показатель степени по числу баров (107 — на сутки короче фактического
периода) — это и было расхождение «107 баров / 108 суток». Выбирать его владельцу не нужно: длительность
определяется датами оценки.
