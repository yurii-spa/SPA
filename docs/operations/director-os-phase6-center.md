# Director OS Phase 6 — Центр директора

READ-ONLY. Первый экран владельца: **что нужно знать и решить сейчас**. Собственной логики
истины здесь нет — центр отбирает уже доказанные записи нижних слоёв и ведёт туда, где они
лежат целиком.

## Чего здесь нет намеренно

| Нет | Почему |
|---|---|
| **общего балла здоровья** | расхождение доставки, просроченный сторож и незакрытая приёмка — разные риски, и сумма их не описывает |
| новой логики истины | ни одно поле не вычисляется заново; `computes_new_truth: false` проверяется контрактом |
| второго списка | у каждого блока «Показать все» ведёт в существующий раздел портала |
| ранжирования «по важности» | порядок только по доказуемому, и он объявлен у каждого блока |
| кнопок | ни `button`, ни `form`, ни `input` — только чтение и переходы |

## Две границы, которые здесь держатся жёстко

**Приёмка.** «Правило применимо, а подтверждения нет» — это проблема. «Применимо ли
правило вообще — не измерено» — это незнание. Сложить их значило бы записать в долги 871
запись KANBAN, на которую ни одно правило приёмки не смотрит. А `NOT_APPLICABLE` не
считается проблемой вовсе и в счётчик внимания не входит.

**Расхождение.** Расхождение — структурное свойство (лишний код в проде, не объявленная
каноничность). «Источник не подтверждает» — свойство наблюдения. `ACTIVE_UNVERIFIED`
никогда не увеличивает системные расхождения, но и не исчезает: у него свой блок.

**Молчание слоя не является «всё хорошо»:** если хоть один слой не прочитан, состояние
системы становится `НЕ ИЗМЕРЕНО` с перечислением непрочитанных.

В блоке расхождений перечисляются **только статусы расхождения**. Первая редакция
показывала топ статусов по численности, и блок открывался строкой `IN_SYNC` (80 объектов) —
то есть совпадением, которое расхождением не является. Исправлено, закреплено тестом.

## Порядок и объём

Не больше **пяти** записей в блоке; счётчик показывает полное число. Контракт отказывает
блоку, где показано больше пяти или больше, чем есть. Порядок объявлен у каждого блока:
severity → ожидание владельца → блокер → свежесть → активность.

## Команды

```bash
python3 scripts/cartographer/director.py \
  --work <Phase 5> --reliability <Phase 4> --authority <Phase 3> --output <новый каталог>

python3 scripts/cartographer/portal.py … --director <каталог> --output <новый каталог>
```

Пишется ровно один файл `director_center.json` (0600) через staging и атомарный `rename`.
Модуль не импортирует ни `subprocess`, ни `socket`, ни `urllib`.
