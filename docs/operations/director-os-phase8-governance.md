# Director OS Phase 8 — Управление и восстановление

READ-ONLY. Новый governance-движок не строится, разрешения не меняются, восстановление не
выполняется. Слой читает существующие решения, правила, границы разрешений и улики
восстановления — и показывает их вместе с тем, **чем каждое доказано**.

## Две границы, которые слой держит жёстко

| Не смешивается | Почему |
|---|---|
| **наличие копии** ≠ **доказательство восстановления** | архив доказывает архив; доказательство — запись о ПРОВЕДЁННОЙ пробе с результатом |
| **описанный откат** ≠ **проверенный откат** | документ и запись об исполнении — разные улики, и вторая из первой не выводится |

Состояния восстановления разведены: `TESTED` · `DOCUMENTED_UNTESTED` · `MISSING` ·
`NOT_APPLICABLE` · `UNKNOWN`. «Документ есть, пробы нет» — это **не** «неизвестно»:
известно ровно то, что пробы нет. Замер: **проверено 1** (`restore_drill_status.json`,
`all_ok: true`), **описано без пробы 7**, отсутствует 0, действительно не измерено 7.
Резервных копий наблюдается 2 источника (локальные архивы + вынесенная копия, сверка
`verified: true`), но **восстановление доказано только пробой**.

## Авторитет цитируется

| Источник | Статус | Чем установлен |
|---|---|---|
| `docs/decisions/*.md` | `AUTHORITATIVE` | CLAUDE.md «решение → ADR (docs/decisions/)»; INDEX.md «Каждое решение, меняющее инвариант… оформляется ADR» |
| `docs/adr/*.md` | **`AUTHORITY_UNDEFINED`** | CLAUDE.md сам называет два реестра с коллизиями: «“ADR-053” неоднозначен». Правила, чей реестр сильнее, нет |
| `docs/decisions/INDEX.md` | `NOT_AUTHORITY` | индекс; решения живут в файлах |
| `.claude/rules/*.md`, `CLAUDE.md` | `AUTHORITATIVE` | «Действующие правила живут только в CLAUDE.md / .claude/rules/» |
| `scripts/code_sync_from_origin.sh` | `AUTHORITATIVE` | сам скрипт объявляет канонический путь и запреты |
| наблюдения (`restore_drill`, `dr_offsite`, `deployment_acceptance`, `code_sync_status`, `security_alerts`, `kill_switch_status`) | `NOT_AUTHORITY` | это наблюдения, а не правила |

**Коллизии номеров ADR не разрешаются:** 7 номеров заняты в обоих реестрах, статус записи —
`NUMBER_COLLISION`, авторитет `AUTHORITY_UNDEFINED`, победитель не выбирается.

## Правило разрешений ≠ ворота одобрения владельца

Род правила определяется по улике, а не по названию:

| Род | Сколько | Требует одобрения |
|---|---|---|
| `OWNER_GATED` — источник прямо оставляет предмет за владельцем | **3** | да |
| `AUTONOMOUS` — «агент решает сам» | **1** | нет |
| `EMERGENCY` — стоп-кран, срабатывает по правилу | **1** | **UNKNOWN**: прямого требования одобрения источник не содержит |
| `UNKNOWN` | 0 | — |

**Ворот одобрения владельца ровно 3**, а не 5: автономное правило и аварийная граница
воротами не являются, и контракт отказывает записи, объявленной воротами без класса
`OWNER_GATED`.

## Область зонирования доказана, а не предположена

Граница ADR-285 говорит о **предметах решений и действий** («включение исполнения, ключи,
платежи… удаление данных, публикация вовне») и отдельно распространена на git/PR. Документ
— ADR, правило, инвариант, runbook, архив — предметом решения не является.

| | |
|---|---|
| зона **требуется** | 8 |
| из них **объявлена** | 5 |
| **требуется и НЕ объявлена** (пробел) | **3** |
| зона **не относится** (вне области) | 118 — **пробелом не считается** |
| область неизвестна | 0 |

## Пробелы измерены, а не перечислены из головы

На живом дереве их 4: процедуры описаны, но ни одна запись об исполнении не найдена у семи
из восьми · 7 коллизий номеров ADR · записи без объявленного владельца · записи, чью зону
разрешения правило не объявляет.

Общего балла управления **нет намеренно**: пробел в резервах и пробел в разрешениях —
разные вещи, и сумма их не описывает.

## Команды

```bash
python3 scripts/cartographer/governance.py --output <новый каталог>
python3 scripts/cartographer/portal.py … --governance <каталог> --output <новый каталог>
```

Пишется ровно один файл `governance_snapshot.json` (0600) через staging и атомарный
`rename`, с `allow_nan=False`. Модуль не импортирует ни `subprocess`, ни `socket`, ни
`urllib`. Значения секретов не копируются: контракт отказывает снимку, в который попала
форма секрета.

## Запрещено

Approve · Rollback · Restore · Rotate secret · Change permission · Change RiskPolicy ·
Trigger kill-switch · Deploy · Delete · Repair. На странице ноль `button` и `form`.
