# Director OS Phase 5 — Разработка и работа

READ-ONLY. Раздел ничего не запускает, не назначает, не принимает и **не заводит задач**.
Он показывает уже существующую работу и у каждого утверждения называет улику.

## Что здесь НЕ создаётся

| Не создаётся | Почему |
|---|---|
| второй бэклог | снимок производный: пересобирается из карточек и журналов, ничего не помнит между прогонами |
| новый workflow | словарь состояний читается из `.nimbalyst/trackers/*.yaml`; исходное состояние хранится рядом с группой владельца, у сведения названа причина |
| исполнитель | `claimed_by` — это заявка, а не агент (см. ниже) |
| «принято» | закрытая карточка без улики приёмки показывается как «завершено, приёмка НЕ подтверждена» |

## claimed_by — это НЕ агент

Замер на живом дереве: **60 заявок, из них агентом не является ни одна.** Там живут
`cycle-663`, `pid94637`, `interactive-session-2026-08-27`. Цикл — это прогон, сессия —
окно, pid — номер, который ОС переиспользует.

| Род | Что это |
|---|---|
| `CYCLE` · `SESSION` · `PID` | не агент, и подписано так прямо на странице |
| `UNVERIFIED_LABEL` | похоже на ярлык launchd, но среди наблюдённых его нет |
| `AGENT_LABEL` | и выглядит как ярлык, **и** подтверждён наблюдением машины (Phase 0) |
| `UNKNOWN` | разобрать не удалось — и это не повод назвать агентом |

Контракт отказывает записи, названной агентом без подтверждающей улики. Без переданного
наблюдения машины подтвердить нечем — тогда агентов ноль по построению.

## Приёмка ≠ завершение

Улик приёмки в этом репозитории ровно две, и обе объявлены правилами: **ответ владельца**
(инв. #14 — решение закрывает владелец, не измерение) и **машинная проба**
(`.claude/rules/acceptance.md`). Проба, ОБЪЯВЛЕННАЯ у карточки, приёмкой не является:
её вердикт нигде не записывается, и выдать объявление за результат значило бы ту самую
самосертификацию, против которой правило написано.

| Состояние | Когда ставится |
|---|---|
| `CONFIRMED` | владелец ответил либо записан вердикт пробы |
| `NOT_CONFIRMED` | закрыто, улик приёмки нет |
| `NOT_APPLICABLE` | `agent-*`: правило само говорит, что к ним не относится |
| `UNKNOWN` | карточка не закрыта |

Замер на живом дереве: `CONFIRMED` 117 · `NOT_CONFIRMED` 409 · `NOT_APPLICABLE` 154 ·
`UNKNOWN` 897. Из 1437 завершённых работ **1335** идут как «завершено, приёмка не
подтверждена».

## Блокер только по улике

Блокером считается прямое состояние карточки (`blocked`, `needs-owner`) и объявленная
зависимость (поле `blocks`). **«Давно не менялось» блокером здесь не считается вовсе**:
правила или SLA на срок работы в репозитории не объявлено, а выдумывать его — тот же
дефект, что выдуманная свежесть в Phase 4.

## Завершение расщеплено по ПРИМЕНИМОСТИ приёмки

| Состояние | Когда |
|---|---|
| `ACCEPTED` | приёмка применима и подтверждена |
| `DONE_ACCEPTANCE_UNCONFIRMED` | применима, подтверждения нет |
| `DONE_ACCEPTANCE_UNKNOWN` | **применима ли — не измерено**: ни одно правило этот род не покрывает |
| `DONE_ACCEPTANCE_NOT_APPLICABLE` | правило само говорит, что не относится |

Замер: завершено 1437 = принято 102 · не подтверждена 362 · не измерено 871 · не требуется
102. Контракт отказывает записи «приёмка не подтверждена» при неизмеренной применимости —
это было бы обвинением по правилу, которое сюда не смотрит.

**Конфликт источников показывается, а не заглаживается:** 15 карточек имеют подтверждённую
приёмку (владелец ответил) при исходном состоянии `owner-done`. Состояние НЕ переписано;
такие записи собраны в блоке «Приёмка подтверждена, а состояние не закрыто».

## Команды

```bash
python3 scripts/cartographer/work.py \
  --reliability <комплект Phase 4> --cartographer <комплект Phase 0> --output <новый каталог>

python3 scripts/cartographer/portal.py --cartographer … --briefing … \
  --authority … --reliability … --work … --output <новый каталог>
```

Пишется ровно один файл `work_snapshot.json` (0600) через staging и атомарный `rename`.
Модуль не импортирует ни `subprocess`, ни `socket`, ни `urllib`.

## Границы

* находка надёжности — **не** задача: объявленная связь показывается как связь,
  совпадение по упоминанию — как возможное, повышения нет;
* в общем списке завершённые работы показаны краткой строкой (четыре поля вместо
  одиннадцати) — при 1577 работах полная форма у каждой давала страницу в 7,8 МБ; полная
  карточка живой работы осталась в блоках выше;
* формы секретов вырезаются из заголовков и улик видимой пометкой.
