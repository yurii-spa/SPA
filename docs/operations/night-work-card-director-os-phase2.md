# Director OS Phase 2 — единый read-only портал студии

> Карточка пакета. Живёт в изолированном worktree. **Ничего канонического не пишется:**
> карточки трекера, решения владельца, манифест и реестр только читаются (инв. #14).

## Роль владельца и цель

Владелец — Yurii. Одна локальная страница, на которой видно: состояние студии и
изменения, существующие задачи с их фактическими статусами, агенты/роли и **доказанные**
связи с работой, существующие запросы решения, и источники с ограничениями данных.

Портал в этой фазе **READ-ONLY**: управление исполнением и изменение канонического
состояния в пакет не входят. Кнопок действий нет намеренно.

## Команды

```bash
cd ~/studio-os-scratch/cartographer-mvp
P=/Users/yuriikulieshov/miniconda3/bin/python3
SNAP=~/studio-os-snapshots

# 1. извлечение + сборка портала (слой A читает источники, B-D собирают страницу)
$P scripts/cartographer/portal.py \
   --cartographer $SNAP/<принятый комплект Cartographer> \
   --briefing     $SNAP/<принятый комплект Owner Briefing> \
   --output       $SNAP/directoros-phase2-$(date +%Y%m%d-%H%M%S)

# 2. OFFLINE-пересборка страницы из сохранённого portal_snapshot.json
$P scripts/cartographer/portal.py \
   --from-portal-snapshot $SNAP/<прошлый комплект портала> \
   --briefing $SNAP/<комплект Owner Briefing> \
   --cartographer $SNAP/<комплект Cartographer> \
   --output $SNAP/directoros-phase2-rebuild-$(date +%Y%m%d-%H%M%S)
```

Каждый запуск пишет в **новый** каталог вне production, вне наблюдаемых деревьев и вне
входных наборов (symlink разрешается). Незавершённый запуск остаётся в
`<output>.incomplete`. Прежние результаты не перезаписываются.

## Что портал НЕ утверждает

- Записанный `done` — не принятая работа. Правило приёмки относится **только к очереди
  inbox** (`.claude/rules/acceptance.md`, раздел «Не относится»), и артефакта с
  результатами проб в наблюдаемом дереве нет.
- `claimed_by` — строка исполнителя (`cycle-663`, `pid98130`, `interactive-session-…`), а
  не метка launchd. Связь с агентом — `UNLINKED`.
- Упоминание метки в тексте записи назначением не является.
- DECLARED / REGISTERED / INSTALLED / LOADED / RUNNING показаны отдельно и не сливаются.
- Где правило каноничности не объявлено — `AUTHORITY_UNDEFINED`.
