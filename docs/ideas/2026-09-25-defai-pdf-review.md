## 🟡 Частично есть — стоит додумать

- [ ] **Чистая доходность по формуле гайда:** доход − вход/выход − мосты/обмены − падение актива
      дохода − цена ошибки. Стоимость переключения есть, единого «net APY после маршрута» на
      позицию нет.
- [ ] **«Кто плательщик»** (заёмщик / трейдер / эмиссия / стимул) — нет обязательного поля у
      пула. Правило «доход в токене награды ≠ доход в долларах» держать явно.
- [ ] **Ликвидность выхода под наш размер** — `portfolio_capacity` / `edge_at_scale` есть, явного
      правила «выход описан до входа» нет.
- [ ] **Health factor / ликвидации** — мониторы есть (`collateral_ratio_monitor`,
      `defi_leverage_safety_monitor`), плечевые стратегии в research; для paper нормально.
- [ ] **Hyperliquid / GMX vaults** («против трейдеров») — только funding/basis в research; если
      брать, то строго T3 / advisory.
- [ ] **Гибрид «основа + эксперимент»** ≈ Conservative/Balanced/Aggressive + T3 ≤ 15 %; сверить
      формулировки, чтобы не было двух словарей.

## ❌ Нет (и нужно ли)

- [ ] **Пользовательский слой:** онбординг-интервью (цель, капитал, время, допустимая потеря в $),
      профиль риска, «паспорт позиции» из 8 вопросов (`monitoring/agent_passport` — про агентов,
      не про позиции). Самая ценная идея гайдов; можно как обучение, без solicitation.
- [ ] **Гигиена подписей / антифишинг:** approve vs transfer, три кошелька, сверка домена через
      DefiLlama — отдельный урок или чек-лист академии.
- [ ] **Uniswap V3 / концентрированная ликвидность** — сознательно НЕ брать до go-live: активное
      управление, не пассивный агрегатор.
- [ ] **ERC-4337 / session keys, Tenderly-симуляция, Privy, чат-помощник** — фаза после go-live и
      legal; предметы №1/№3 границы (ADR-285), решает владелец.
- [ ] **Кросс-чейн мосты** — отдельный класс риска; только через RiskPolicy.
- [ ] **DCA из дохода в BTC/ETH** — не профиль стейбл-агрегатора; максимум advisory-sleeve.

## Рекомендация

Забрать методологию гайдов (net-доход, «кто платит», выход до входа, паспорт позиции, гигиена
подписей). Из ТЗ — только инфраструктуру на будущее (Safe/4337, симуляция). LLM-агентов,
решающих про деньги, — не брать: здесь наша архитектура сильнее.
