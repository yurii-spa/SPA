# AI1 for SPA: One-Pager

## За 60 секунд

**Проблема:**  
SPA сейчас — система на памяти людей. Allocation Logic, APY Truth, проверка тиров, Rebalance Trigger — всё в голове owner-а или неявных эвристиках.  
Для go-live с реальным капиталом это не масштабируется.

**Решение:**  
Применить AI1 (методология из книги Gamzatova "Бизнес, понятный машинам"):
1. Сделать бизнес-логику **явной** (машиночитаемой)
2. Построить **агентов** вокруг явных правил (0 LLM в risk)
3. Масштабировать по **контролируемому плану** (30/90/180/365)

**Результат на Day 365:**  
- ✅ Allocation Auditor: каждый день автоматически проверяет политику
- ✅ APY Evidencer: гарантирует freshness данных
- ✅ Tier Validator: автоматизирует проверку, owner решает за 30 мин вместо часов
- ✅ Rebalance Automation: dry-run плана, fail-CLOSED выполнение
- ✅ Go-Live: $100K+ готов к live-запуску

## Три Агента (кто это, что делает)

### 1️⃣ Allocation Auditor (Месяц 1)
**Ежедневно проверяет:**
- Соответствие текущей аллокации RiskPolicy v1.0
- Нарушение потолков концентрации
- Возможности ребаланса (cost vs benefit)

**Результат:** `allocation_audit.json`  
→ Owner читает, принимает решение быстро

### 2️⃣ APY Evidencer (Месяц 2)
**Каждый цикл собирает:**
- Источник каждого APY-числа
- Evidence-level (L0-L6)
- Freshness (когда получено)
- Расхождения между фидами

**Результат:** `apy_evidence.json`  
→ Site Custodian автоматически обновляется, 0 stale на публике

### 3️⃣ Tier Validator (Месяц 2-3)
**Проверяет критерии:**
- TVL ≥ $5M/пул?
- История стабильности ≥ 30 дней?
- Security score?

**Результат:** `tier_assessment.json` (чек-лист)  
→ Проверка владельцем: вместо часов → 30 минут

## Инвестиция vs Выигрыш

| Инвестиция | Выигрыш |
|-----------|---------|
| 1-2 неделі owner-time на явные описания | Risk-drift на 0 (Allocation Auditor каждый день) |
| 3 месяца разработки Claude | Масштабируемость для $100K+ (не растёт owner-load) |
| Тесты для каждого агента | Fail-CLOSED гарантия: капитал не двигается на неполных данных |
|  | Go-Live вместо 6 месяцев → 12 месяцев, но честно |

## Почему AI1, а не LLM?

❌ **Нельзя:** `ChatGPT решает аллокацию`  
- Нарушает инвариант: LLM FORBIDDEN в risk-логике
- Невозможно верифицировать
- Регулирование не пройдёт

✅ **Можно:** `Детерминированный агент + явные правила`  
- Каждое решение — факт в JSON
- Verifiable, reproducible
- Fail-CLOSED: если данные неполные → STOP, не угадываем

## Ответы на Частые Вопросы

**Q: Это затянет go-live?**  
A: Нет, ускорит. Сейчас go-live требует owner внимания 24/7. С AI1 это масштабируется.

**Q: Что если агент сломается?**  
A: Fail-CLOSED: если агент не ответит за 10с → HALT, капитал не двигается.

**Q: Нужен LLM?**  
A: Нет. Все агенты = детерминированные правила. LLM запрещён в risk-логике (инвариант).

**Q: Когда go-live?**  
A: День 180 (месяц 6): $1-10K live. День 365: $50-100K live.
