# Owner package · устаревшее публичное число «~3.3% realized» (предмет №2)

> Дата: 2026-10-01 · связано: ADR-292 (одна точка правды для ставки), ADR-531 (P0-4) ·
> карточка-предшественник: `owner-decision-sait-why-20-apy-means-tail-risk-astro-i` (одобрена 16.09, не выкачена).

## Что не так

Сайт в семи отрисованных местах печатает ставку Conservative литералом **«~3.3%»**. Это замер июля.
Та же ставка, отрисованная из витрины, на тех же страницах и рядом показывает **4.9%** (замер
2026-10-01). Читатель видит две разные «фактические» ставки одного трека.

## Почему число ещё на сайте (дефект доставки, не решения)

09.09 шестнадцать файлов переведены на общий источник (коммит `2da9918e`). Три оставшихся
сторож owner-gate задержал (`honesty.token.removed`: в тех же строках стоит «refused for live»),
и завёл карточку. **16.09 ты её одобрил**, но карточка получила статус `ingested`, а не
`owner-done`, а сторож пропускает правку только по `owner-done`. Пуш так и не случился, и две
недели этого никто не видел. Кроме того, ссылка «15% vs the real ~3.3%» на `/packages` в ту
карточку не входила вовсе.

## Что ставить вместо литерала

**Не «4.9» вместо «3.3»** — это был бы тот же дефект с новой датой. Источник уже есть и им
пользуются шестнадцать файлов:

- `landing/src/lib/realized_rate.js` → `realizedPhrase(null, ru)`: «~4.9% realized (measured 2026-10-01)» /
  «~4,9% фактических (замер 2026-10-01)». Читает витрину `landing/src/data/site_numbers.json`
  (`headline.apy`, источник — `track_snapshot.json`; публикация недельная, дата замера в фразе).
- Для ссылок (#2, #6), где нужна короткая форма: `realizedApyLabel(null, ru)` → «4.9%» / «4,9%».
- Нет значения в витрине ⇒ функция печатает «realized rate unavailable», а не последнее число.

«15%» в ссылках — не наша ставка, а число страницы `/annual-contrast` (берёт его из API лаборатории).
Пакет его **не трогает**.

## Что пакет НЕ меняет

Остальной текст тех же строк остаётся дословно: «up to 6%», «the REAL live paper book», «evidenced»,
«refused for live», «research/paper, shown WITH the tail» и т. д. Новых обещаний, чисел и формулировок нет.

**Рядом, но вне пакета (для твоего решения отдельно):** в #5 стоит «with 0.0% drawdown» — тоже
литерал-замер. В витрине есть `drawdownPhrase()`, но она добавляет пояснение, то есть меняет
текст. По умолчанию не включаю.

## Варианты

- **A (рекомендую):** одобрить #1–#6 — литерал заменяется рендером из витрины, по сайту одна ставка,
  и она обновляется сама.
- **B:** одобрить выборочно (номера).
- **C:** не менять.

## Как довести после ответа

Одобрение = карточка этого пакета в `owner-done` с `approves:` на три файла; пуш через
`scripts/safe_site_push.py` с трейлером `Owner-Approved: <id карточки>`; затем проверка
`curl -L` трёх страниц: «3.3» нет ни в одном отрисованном месте, ставка совпадает с главной.
