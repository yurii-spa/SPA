# ADR-078 · Мандат десятидневной автономии (2026-08-09 … ~2026-08-19)

- **Статус:** Accepted (владелец, интерактивная сессия 2026-08-09, перед отъездом на 10 дней)
- **Дата:** 2026-08-09
- **Автор/утвердил:** сессия-архитектор (Claude) / владелец

## Контекст

Владелец уезжает на 10 дней и требует: система продолжает разработку САМА, решения принимаются
автономно, бэклог ведётся сам; **если задачи кончились — архитектурная сессия формирует новые**.
Очередь `needs-owner` на момент отъезда — ПУСТА (10 карточек разобрано в тот же день).

## Решение

### Разрешено решать самому (без карточки владельцу)

- **Архитектура, код, тесты, документация** — включая новые ADR по не-риск-темам.
- **Агенты флота**: запуск, ретайр, изменение расписаний, деплой через штатный gate.
- **Paper-книги и их капитал**: масштабирование, засев, новые advisory-книги
  (все три пакета — Conservative / Balanced / Aggressive).
- **Приоритеты бэклога**, направления R&D, порядок работ.
- **САЙТ — расширено**: статусы тиров и любые тексты **БЕЗ новых чисел доходности**
  шиплю сам (владелец 09.08). Числа доходности, нейминг тиров, legal/solicitation —
  по-прежнему через owner-gate → карточка, копится до возвращения.
- **Yield-триггер ADR-060 — расширено**: при ОДНОВРЕМЕННОМ выполнении всех трёх критериев
  (≥30 дней shadow · net > 0 · hit-rate ≥ 60%) **взвожу автоматически** и пишу владельцу в
  Telegram. Пороги критерия не меняются; при любом сомнении — не взводить.
- **Ретайр advisory-аналитики** после 4 недель измеренной бесполезности (ADR-067, в силе).
- **Откаты**: при измеренной деградации откатываю СВОЁ изменение сам, в тот же час, с записью.

### Запрещено в любом случае (ждёт возвращения владельца)

1. **Пороги RiskPolicy v1.0** и лестница kill-switch (SOFT −5% / HARD −10%) — не трогать.
2. **Реальный капитал / go-live / execution** — не приближаться (paper остаётся paper).
3. **Числа доходности, нейминг тиров, legal-формулировки на сайте** — owner-gate.
4. **Активация Head-of-Investment (ADR-055)** как решающего слоя — owner-gated.
5. **Секреты, настройки репозитория, launchd вне штатного gate, удаление данных.**

### Когда задач нет — формировать самому

Приоритет источников новых задач:
1. **Петля ADR-066**: находки сторожа, gap-анализ, еженедельное ретро → карточки автоматически.
2. **Каталог аудита (ADR-071)**: прогон известных классов дефектов по неохваченным подсистемам.
3. **Архитектурная сессия**: если оба источника сухие — сессия проводит ревизию (money-path,
   доходность, надёжность, честность) и формирует задачи сама, записывая обоснование.
4. **R&D** (`novel_edge_rnd`, ежедневно): новые edge-идеи с честным бэктестом.

Правило: **пустой бэклог — это находка, а не отдых.** Пустая очередь означает, что
никто не смотрел достаточно глубоко.

## Последствия

- Ежедневный Telegram-дайджест владельцу продолжает уходить (постура офиса, конформанс,
  петля, три трека) — он остаётся окном в систему на время отсутствия.
- CRITICAL: карточка + Telegram немедленно + безопасный фикс R1–R3 (ADR-067, в силе).
- Все автономные решения записываются в журнал и ADR; по возвращении владельца — сводка
  «что решено без тебя» одним списком.
- Дисциплина неизменна: тесты в обе стороны, sandbox для money-path, acceptance до/после,
  инварианты 14/16, правки поверх свежего origin.
