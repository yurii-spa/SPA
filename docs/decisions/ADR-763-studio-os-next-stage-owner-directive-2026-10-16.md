# ADR-763 · STUDIO-OS-NEXT-01: следующий этап Earn DeFi Studio OS по плану ARB (директива владельца 16.10)

- **Статус:** Accepted — директива владельца 2026-10-16 (задание «выполнить следующий этап улучшений Earn DeFi
  Studio OS по плану ARB»). Записано агентом дословно по составу; формулировки владельца не переписаны.
- **Дата:** 2026-10-16
- **Автор/утвердил:** владелец (директива) · агент Claude Code (запись, исполнение)
- **Связано:** ADR-285 (три предмета владельца), ADR-527 (единый роадмап и память), ADR-610 (непрерывность),
  ADR-611 (классы архивов), ADR-660/661 (волна 1), ADR-760 (голосовой ввод), ADR-762 (пульт и граница
  подтверждения), хендовер 15.10 (`HANDOVER_FOR_CHATGPT_2026-10-15.md`, вне репозитория).

## Контекст

15.10 выпущены волна 2 сайта (`0dc759eb2`), новый пульт (`2df987cec`) и голосовой ввод (`a3e3b38c6`,
`fd2650660`). Хендовер 15.10 перечислил 34 незавершённых пункта пульта и открытые вопросы: ресурсы Mac
(перед перезагрузкой 15.10 swap 92,9 %, процесс `findings_bridge` ~5 ГБ), сборка пульта 17–22 мин,
еженедельный бэкап загружен и падает, отправка голосом с iPhone не проверена, ADR-762 — только предложение.
`docs/ROADMAP.md` в последний раз подтверждён владельцем 01.10 и выпусков 08–15.10 не отражал.

## Решение (директива владельца, порядок исполнения)

1. **Роадмап.** Актуализировать `docs/ROADMAP.md` (единственный роадмап, ADR-527): волна 1/2, Director OS,
   голосовой ввод, единая методика доходности, переименование ADR-690 → ADR-762. Старые финансовые показатели —
   только как датированная история. Различать: реализовано · опубликовано · проверено владельцем · принято ARB;
   незавершённую приёмку не закрывать. Свести 34 пункта списка 15.10 с роадмапом без повторных карточек.
2. **Ресурсы Mac и скорость пульта** — первый рабочий пакет: фактически исполняемый код, источник сообщений
   Telegram о перегрузке памяти, `findings_bridge`, `mission_build`, одновременные тяжёлые задачи, устаревшие
   имена `director_*` в `architecture/resource_policy.json`. Замеры обычного запуска, без стресс-теста.
   Доказанная причина отдельно от гипотезы. Не ослаблять проверки и не поднимать пороги ради зелёного.
   Уведомления различают RAM, swap и диск, показывают время, абсолютные величины и главных потребителей.
3. **Резервирование** — второй пакет: таблица покрытия, закрытие пробелов в кандидате, проверка восстановления в
   отдельной папке. Файл в папке iCloud не есть доказанная загрузка на сервер. Только после подтверждения
   покрытия — подготовленное (не выполненное) решение об отключении `com.spa.weekly_backup` с откатом.
4. **Голосовые задачи**: путь iPhone → расшифровка → правка → отправка → ровно одна карточка → обработка →
   понятный статус владельцу; повторная отправка и сбой соединения. Карточка не разрешает финансовых,
   публичных или необратимых действий.
5. **ADR-762** — реализация защиты версии решения в отдельном кандидате (проверка и запись под одной
   блокировкой, защита от повторов, журнал и восстановление, безопасное отключение записи); в работающий
   механизм подтверждений без отдельного разрешения не включать. Следом: история стоимости пакетов, понятные
   причины предупреждений, кнопки проверок только для чтения, финансовые доказательства.

## Ограничения (часть директивы)

Ничего не удалять (архивы, история, карточки, рабочие копии, данные); без reset/clean и массовых коммитов;
настоящий капитал $0, финансовые лимиты и допуски не менять; публикации, перезапуски работающих служб и
изменение механизма подтверждений — через существующие разрешения владельца; не создавать вторую систему
памяти или второй роадмап; не расширять рынки и не запускать реальную торговлю; проверки выбирать по риску
и затронутым участкам, а не полный семичасовой набор на каждую правку.
