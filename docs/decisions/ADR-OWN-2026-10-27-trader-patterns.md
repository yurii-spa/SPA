# ADR-OWN-2026-10-27 — перенести полезные идеи trader-skill в бэклог SPA

Дата: 2026-10-27, Europe/Madrid. Владелец: Юрий. Запись и оценка: ChatGPT / ARB.
Статус: ACCEPTED_FOR_BACKLOG; внедрение, новые лимиты и реальный капитал не разрешаются этой записью.

Источник: просьба владельца изучить документ trader-skill-takeaways-for-spa.md, оценить полезность,
записать идеи и новые задачи в roadmap/бэклог. Документ прочитан целиком; GitHub найден в нём.

Решение: выделить TRADING-PROCESS-01 — совершенствование существующего research/paper/shadow процесса.
P1: воспроизводимость одного цикла, проверка совокупного состояния после заявок, привязка версий
намерения/риска/полномочий, свежесть и идемпотентные события. P2: атрибуция результата и ограниченный
paper-эксперимент sizing/ребаланса. P3: публичные on-chain-портфели как исследовательский источник.
Подробные задачи: ../tasks/trader-patterns-backlog-2026-10-27.md.

Обоснование: в SPA уже есть реестр, контракты, детерминированный Trading Research, paper-evidence,
shadow-intents и push-policy. Полезен перенос контрольных сценариев и повышение прозрачности,
а не повторная разработка компонентов или обещание дополнительной доходности.

Альтернативы: установить весь пакет и его broker (отклонено); не брать ничего (потеря полезных
контролей); адаптировать проверенные подходы с переиспользованием существующих механизмов (выбрано).

Последствия: существующий forward продолжается, история не сбрасывается. Новые эксперименты имеют
новые ID и собственное evidence. Текущий большой пакет эксплуатации не расширяется незаметно;
совпадающие задачи связываются. Изменение финансовых параметров, публичных утверждений и live execution
остаётся за действующими решениями владельца. Код стороннего репозитория не устанавливался.
