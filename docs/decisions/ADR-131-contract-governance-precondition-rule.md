# ADR-131 · Ограничение в шаблоне договора — общее правило governance-предусловия, без имени протокола

- **Статус:** Accepted
- **Дата:** 2026-08-25
- **Автор/утвердил:** владелец (Telegram, 2026-08-25T10:23:21Z, вариант 2); исполнил оркестратор, цикл #381

## Контекст

Инвариант «Sky/sUSDS = 0 % до подтверждения GSM Pause Delay ≥ 48h on-chain» был **выполнен
05.08.2026** (48.00 ч замерены on-chain, три независимых RPC) и снят **ADR-065**: протокол
переведён из наблюдения в T1.

Цикл #380 привёл в порядок восемь живых справочников, которые продолжали объявлять снятый
запрет действующим — класс прозы, из-за которого 16.08 агент триажа назвал КРИТИЧНЫМ нарушением
живую строку кода. Один файл цикл #380 намеренно НЕ тронул: строка 354
`docs/legal/DOGOVIR_PROSTOGO_TOVARYSTVA_TEMPLATE.md`. Это **условие договора**, а не справочная
фраза, и правку договорного текста делает владелец. Файл был назван поимённым исключением
`_SUSDS_OWNER_GATED_DOCS` в `spa_core/tests/test_doc_drift.py` с указанием карточки-вопроса.

Вопрос ушёл владельцу карточкой `owner-decision-v-shablone-dogovora-ostalos-snyatoe-ogra`
с тремя вариантами (убрать пункт · переформулировать в общее правило · оставить как снимок на дату).

## Решение

**Вариант 2 владельца.** Пункт Б.3 шаблона больше не называет ни одного протокола. Вместо
снятого условия — общее правило, переживающее любой протокол:

> Протокол, безпека якого спирається на governance-передумову (затримка паузи, таймлок тощо),
> допускається до портфеля **лише після підтвердження цієї передумови on-chain**; до
> підтвердження його частка — 0%.

Следом снято исключение из сторожа: `_SUSDS_OWNER_GATED_DOCS` теперь **пуст**, а шаблон
проверяется наравне с любым живым документом.

## Последствия

- **Плюс.** Договор, который однажды поедет живому человеку, не объявляет действующим ограничение,
  которого у нас нет. Правило сформулировано механизмом (governance-предусловие), а не именем —
  следующий протокол того же класса не потребует новой правки договора и новой карточки.
- **Минус (честно).** Общая формулировка не называет порог: «затримка паузи ≥ 48h» из текста ушла.
  Конкретика живёт в RiskPolicy v1.0 и ADR-065, на которые договор уже ссылается; в договорном
  тексте это осознанный размен конкретики на долговечность.
- **Пустой allowlist — не украшение.** `_SUSDS_OWNER_GATED_DOCS = {}` делает свой же тест
  (`test_susds_owner_gated_exception_is_named_with_a_reason_and_still_needed`) вакуумным по
  построению, поэтому зубы перенесены в новый
  `test_susds_legal_template_is_scanned_like_any_living_doc`: шаблон обязан быть в корпусе
  сканера, НЕ быть ни в одном списке исключений и не содержать активного запрета. Молчаливый
  возврат файла в исключения теперь краснеет — «переоткрыть решённый вопрос тихо» невозможно.
- **Приёмка — три мутации, все красные, восстановленное дерево зелёное:** (1) вернуть в шаблон
  дословную строку 354; (2) молча вернуть файл в `_SUSDS_OWNER_GATED_DOCS`; (3) ослепить
  `_SUSDS_GATE` — падает положительный контроль на дословном довправочном тексте, который
  добавлен в `_SUSDS_PRE_FIX_SNIPPETS` этим же решением.
- **Не сделано и НАЗВАНО.** В том же разделе Б.3 живёт ВТОРОЕ расхождение договора с политикой:
  «T2 разом: ≤ 35%» при живом `RiskConfig.max_total_t2_allocation = 0.5` (50 %; сам changelog
  политики фиксирует «ADR-019 (2026-06-12): T2 cap 35%→50%»). Это тоже условие договора ⇒ молча
  не правим — карточка `owner-decision-dogovor-nazyvaet-staryi-potolok-t2-35-pr`.
- **Затронуто:** `docs/legal/DOGOVIR_PROSTOGO_TOVARYSTVA_TEMPLATE.md` (Б.3),
  `spa_core/tests/test_doc_drift.py` (+2 теста, +1 положительный контроль, −1 исключение).
  RiskPolicy, пороги, kill-switch, трек — **не тронуты**.
