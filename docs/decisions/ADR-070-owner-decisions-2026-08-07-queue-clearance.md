# ADR-070 · Пакет решений владельца 2026-08-07: очередь разобрана полностью (22 решения)

- **Статус:** Accepted (интерактивная сессия 2026-08-07, структурированные вопросы с рекомендациями)
- **Дата:** 2026-08-07
- **Автор/утвердил:** сессия-архитектор (Claude) / владелец

## Контекст

В очереди накопилось 22+ карточки `needs-owner` (часть с 31.07). Владелец разобрал ВСЮ очередь
в чате четырьмя раундами + батч own-30 + 2 R&D. Ни одной карточки, ждущей владельца, не осталось.
Отдельно в этой же сессии: мандат «кэш срочно в работу» (реализация — ADR-069) и «3 paper-трека»
(реализация — отдельным ADR), «аудит-как-код» (ADR-071).

## Решения (владелец выбрал; ✅ = уже исполнено в сессии)

### Операционные
1. **rtmr_sense перезапустить** → ✅ перезапущен (kickstart, новый код).
2. **Канон трека в git**: ночной цикл коммитит `equity_curve_daily/golive_status/paper_trading_status`
   вместе с сайтом — числа сайта воспроизводимы из GitHub, сторож проверяет реально.
3. **Owner-gate сайта**: узаконить класс «ежедневный снимок трека» (строго 5 полей из дневного
   цикла) — вывести из-под гейта; красный снова = тронули тиры/legal/оффер.
4. **Стоп-кран тревога**: добавить resolve-«выздоровление» четырём застрявшим событиям
   (стоп-кран снят/агент поднялся → состояние «хорошо»), чтобы следующая настоящая тревога звучала.

### Архитектурные
5. **Дубль-сторож**: живой контур остаётся, в него переносятся 3 гарантии из дубля
   (молчащий источник НЕ закрывает карточки — подтверждённый реальный дефект моста; названный
   отказ — не находка; третья по тексту карточки), дубль потом удаляется.
6. **morpho_steakhouse риск-оценка** = оценка `morpho_blue` (один vault — один риск); CI гаснет честно.
7. **Защита общей памяти**: точечный fail-CLOSED для `docs/STATE.md`, `docs/journal/*`, `_BOARD.md`
   при неизмеримой базе пуша; остальное как есть.
8. **Фаза 2 расширения протоколов**: привязана к событию go-live, не к календарю.
9. **Замок цикла оркестратора**: общий файл-замок (atomic-mkdir) на весь цикл; занят живой
   сессией — вежливый выход; ручной запуск видит «подожди N минут».
10. **«Упоминание ≠ захват» подтверждено**: блокируют только явный захват и живая сессия.

### Оповещения
11. **Digest-обёртка**: честный код возврата (не ушло — ошибка, agent_health видит).
12. **BTS-алерты**: сначала честный порог (сравнение с НАШЕЙ доходностью, без выдуманных $20k),
    затем включить в Telegram.
13. **Гашение тревоги «core agent down»**: agent_health по двум чистым снимкам подряд
    (консервативнее рекомендации — выбор владельца).
14. **governance_watcher**: чужих убрать поимённо (balancer, curve, lido, maker, uniswap-v3,
    yearn — «watched but not investable»), добавить источники голосований ДЕРЖИМЫХ
    (aave_v3, pendle, maple, morpho) и далее вайтлист по мере наличия каналов; покрытие
    было 2/36 при непокрытых held.

### Данные и реестр
15. **Выдуманная казна 2% TVL в оценке страховки**: отказываться (fail-CLOSED, «не измерено»),
    с проверкой, что UNCHECKED не блокирует протоколы на пустом месте.
16. **Дыры трека и go-live**: блокируют только АКТИВНЫЕ дыры (сегодня 0); исторические
    (19.07, 27.07 — невосстановимы by design) остаются в отчёте навсегда, но не блокируют бессрочно.
17. **`frax`**: дубль удалить из реестра (единственный инструмент закреплён за `sfrax`).
18. **`notional_v3`**: признать неподдерживаемым (не ERC-4626) и вывести до отдельного разбора.

### Подтверждения
19. **Решения 23.07 в силе**: путь D→B, слой Head-of-Investment (ADR-055), 3-тировая оценка.

### R&D и новый класс
20. **CLMM «79%»**: исследование + захеджированная форма (нога ETH под шортом) — правка правил
    допуска = отдельный ADR risk-слоя, пускать класс только с подтверждённым хеджем.
21. **R&D CDR #39** (демоушен с отложенным возвратом; 23.3% против 17.9% после издержек,
    просадка −3.37% против −5.44%): завести paper-модуль на форвард (advisory, вне RiskPolicy).
22. **R&D dwell-защёлка** (2 плюсовых дня до возврата; просадка на треть мельче): завести
    paper-модуль на форвард.

Плюс мандаты сессии: **кэш сверх буфера обязан работать** (ADR-069, срочно),
**R&D novel_edge_rnd ежедневно 04:00** → ✅ передеплоен персистентно,
**3 paper-трека поэтапно** (фикс aggressive-книги → единая отчётность → турнир-база),
**аудит-как-код** (ADR-071: каталог классов дефектов + семантические проверки + месячный свип).
