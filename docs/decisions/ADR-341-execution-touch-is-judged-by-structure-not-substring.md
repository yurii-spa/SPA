# ADR-341 — «Трогает execution» в паспорте конвейера судится структурой, а не подстрокой

**Дата:** 2026-09-11
**Статус:** принято (агент, ADR-285: сторож паспортов, не деньги и не публичные числа)

## Находка

Красный CI шаг 2: `test_pipeline_rights_and_limits::test_a_clean_pipeline_says_so` — конвейер
оркестратора получил ограничение «ТРОГАЕТ execution — money-path». Причина:
`fill_agent_passports.limits_from_shell` искал ПОДСТРОКУ `spa_core.execution` /
`spa_core/execution` в тексте обёртки и её шагов, а `consume_office_reports.py:2020`
упоминает `spa_core/execution/` в строке прозы. Класс ADR-338: суждение о структуре по тексту.

Замер по всему флоту (103 обёртки с ограничениями, старая мерка против новой):

- **6 ложных «ТРОГАЕТ»**, каждое проверено координатой: проза оркестратора; список запретных
  доменов и путей сканирования `rules_watchdog`; докстринг цикла «Does NOT import
  `spa_core/execution/`» (у `run_daily_paper_cycle.sh` и `check_agent_before_deploy.sh` —
  буквально наоборот); список защищённых путей `sprint_coordinator`; пути файлов в пушере.
- **Обратная ловушка, найденная до записи:** `golive_freshness_cycle` запускает
  `[PY, "-m", "spa_core.execution.owner_blockers"]` ПРОЦЕССОМ, без импорта. Чисто импортная
  мерка соврала бы «не трогает» про конвейер, который исполняет execution.
- **8 «чисто», не прочитавших ни строки:** ненайденный файл шага молча пропускался
  (`uvicorn`, `http.server`, `tracker_status_sentinel` без распознанной цели, отсутствующий
  `scripts.spa_admin`, пакеты с `__init__.py`), и конвейер объявлялся чистым.

## Решение

Шаг трогает execution, если (а) его имя — модуль execution; (б) его исходник ИМПОРТИРУЕТ
execution по AST (`import`, `from … import`, в т.ч. `from spa_core import execution` и
относительный импорт, разрешённый от имени модуля; `import_module`/`__import__`/`run_module`
со строкой); (в) ЗАПУСКАЕТ его по форме argv — в литерале списка за `"-m"` стоит модуль
execution, или строка команды содержит `-m spa_core.execution…`. Проза, списки доменов и
пути для чтения этой формы не имеют.

Третий исход «execution: НЕ ИЗМЕРЕНО — <причина>»: шаг из репозитория не найден или не
парсится, либо у конвейера есть шаги, но ни один не прочитан. Метки `agent_template.sh <имя>`
и чужие программы не считаются непрочитанными шагами (их верхнего пакета в репо нет).
Обёртка вовсе без питоновских шагов по-прежнему «не импортирует» — ответ измерен разбором.

Хранимые паспорта в `architecture/manifest.json` не меняются: у генератора заполненное поле
старше выведенного; отчёт `--check` до и после идентичен.

## Приёмка

- Красный тест зелёный; 12 новых сцен (`ExecutionIsJudgedByStructureNotBySubstring`), в т.ч.
  живой положительный контроль `agent_golive_freshness.sh` → «ТРОГАЕТ».
- Батарея 10 мутаций по координатам — 10/10 красные (две выжившие закрыты сценами: пропуск
  рядом с чистым шагом; шаг-пакет).
- Смежные наборы паспортов: 145 passed.
