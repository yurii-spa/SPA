# ADR-294 · Balanced и Aggressive: наблюдаемые ставки, списанные издержки, шов переоценки

- **Статус:** Accepted
- **Дата:** 2026-09-09
- **Автор/утвердил:** оркестратор — реализация решения **владельца** [ADR-292](ADR-292-real-paper-tracks-for-both-advisory-books.md)
  («сразу настоящий, обе книги»)

## Что было измерено перед работой

ADR-292 назвал покрытие обеих книг наблюдёнными ставками равным 0.0 %. Замер повторён
2026-09-09 перед правкой — и оказался точнее, чем «не наблюдается»: **наблюдение было, но
проигрывало константе**.

В живом `data/apy_ranking.json` того дня 30 строк, из них 8 несут `apy_source="fallback"`.
Все четыре верхние по доходности — константы:

| строка | APY | apy_source | tvl_source |
|---|---|---|---|
| `pendle_yt_susde` | 14.00 | **fallback** | static |
| `ethena_susde` | 12.00 | **fallback** | static |
| `moonwell_base` | 11.97 | live | live ($238 тыс. — ниже пола) |
| `aerodrome_usdc_lp` | 8.50 | **fallback** | static |
| `pendle` | 8.00 | **fallback** | static |
| … | | | |
| `maple` | 4.96 | live | live ($2.7 млрд) |

Отбор кандидатов сортировал по `(−apy)` и не спрашивал происхождение. Поэтому обе книги
**детерминированно** набирались из литералов: Balanced держал ровно 14.0 / 12.0 / 8.5 / 8.0.
Это не случайность фида — это следствие того, что константа адаптера ставится оптимистично, а
значит всегда обгоняет наблюдение.

Отдельно: поле истории называлось `accrual_basis = "per_position_live_apy"`. Слово «live» там
значило «из файла ранжирования», а не «наблюдено», — **претензия на провенанс, которую никто не
проверял**. Тот же класс, что уже ловили на `tvl_source` (ADR-053): «never stamp `live` on a
constant».

## Решение

1. **Провенанс — условие допуска.** `sleeve_book.observable_rows()`: строка становится
   кандидатом, только если `apy_source == "live"`, `tvl_source == "live"` и `tvl_usd >= $5M`
   (пол RiskPolicy v1.0 — книга-рукав не смягчает границы политики). Отсутствие поля — **отказ
   с названной причиной**, а не «по умолчанию можно»: иначе старая фикстура или новый адаптер
   без поля тихо вернули бы прежнее поведение. Причины отказа возвращаются вызывающему списком.
2. **Базис переименован** в `per_position_observed_apy` — имя больше не утверждает того, что не
   проверено.
3. **Абсолютный порог полосы 6 % снят** (`book_candidates`). Против наблюдённых ставок он
   опустошал книгу ЦЕЛИКОМ: лучшая наблюдённая ставка, проходящая пол TVL, была 4.96 %. Книга,
   которая по построению никогда не открывает позицию, — не тест, а отказ. «High-yield» стало
   величиной относительной: список отсортирован по доходности, а профиль книги решает, сколько
   имён с начала взять (Balanced 4 по 40 %, Aggressive 2 по 60 %). **Доступ при этом стал
   строже, а не мягче**: ненаблюдаемая ставка больше не кандидат вовсе.
4. **Издержки перекладок списываются.** `book_move_cost()` — газ на затронутую позицию,
   слиппедж на **односторонний** оборот `max(куплено, продано)`, мост при нескольких сетях.
   Числа берутся из **единственной** модели костов дерева
   (`spa_core/backtesting/tier1/cost_model.py`), той же, которой пользуется
   `rebalance_economics`; четвёртое число на этой оси не заводится.
5. **Переоценка — шов с третьим исходом.** `mark_to_market()` двигает кривую только по
   НАБЛЮДЁННЫМ ценам (сегодня единственный источник — монитор пега, покрывает 1 из 4 позиций
   книги). Непокрытая нога не переоценивается, а доля покрытия пишется **числом в каждую строку
   истории** (`mtm_coverage_pct`): «не измерено» и «не двигалось» дают одинаковый ноль P&L, и
   различить их обязан потребитель. Имена сопоставляются точно — «похожие» имена не склеиваются,
   потому что ошибка сопоставления здесь означала бы переоценку позиции по цене чужого инструмента.

## Результат замера — тот, что ADR-292 назвал ЗАРАНЕЕ

| книга | было (литералы) | стало (наблюдено) |
|---|---|---|
| Balanced | 10.52 % | **4.70 %** (maple 4.96 · fluid 4.83 · susde 4.73 · morpho_steakhouse 4.28) |
| Aggressive | 13.01 % | **4.90 %** (maple 4.96 · fluid 4.83) |
| Conservative (для сравнения) | 5.31 % | 5.31 % |

Покрытие наблюдёнными ставками: 0 % → **100 %** (позиция, которую нельзя наблюдать, не
открывается вовсе). Издержка первого развёртывания $100 тыс. в четыре имени — **$128.00**
(газ $48 + слиппедж $80), при дневном доходе $12.88: **день первый закрывается в минус $115.12**.
Кривая книги впервые способна упасть.

Числа 12 % и 20 % в наблюдаемой вселенной отсутствуют. Это и есть ответ теста.

## Приёмка ADR-292 — построчно

| пункт | состояние |
|---|---|
| покрытие наблюдёнными ставками 0 % → 100 % | **выполнено** |
| кривая МОЖЕТ падать | **выполнено** — издержками (замер: −$115.12 в день открытия) |
| издержки списаны, сумма > 0 | **выполнено** (`costs_paid_usd` в state, `cost_usd` в каждой строке) |
| переоценка по движению цены | **шов построен, покрытие 25 %** — единственный источник цен в дереве покрывает 1 из 4 позиций; это записано числом, а не умолчанием |
| пересчёт кривой из сохранённых входов | **не сделано** — отдельная работа, обвязка консервативного переносится следующим заходом |
| публичные числа обеих книг на сайте | **не сделано** — owner-gated класс (ADR-286 §2), уедет карточкой после первого цикла на новом коде |

Два последних пункта названы вслух, а не тихо опущены.

## Контроль

`spa_core/tests/test_sleeve_book_and_cio_directive.py` — 47 тестов, 12 новых. Положительный
контроль класса (`test_the_2026_09_09_shape`) строит ровно тот файл ранжирования, который в тот
день профинансировал обе книги литералами.

Батарея мутаций по координатам, каждая снята после прогона (6 из 6 пойманы):

| мутация | пойман |
|---|---|
| гейт наблюдаемости отключён | `test_the_2026_09_09_shape` |
| издержка не списывается (Balanced) | `test_bar_holds_real_positions…` |
| издержка не списывается (Aggressive) | `test_lp_bar_holds_real_positions` |
| пол TVL снят | `test_tvl_floor_is_the_policy_floor` |
| отметка цены не запоминается | `test_first_observation_marks…` |
| односторонний оборот → `gross/2` | `test_deploying_cash_is_not_halved` |
| непокрытая нога считается покрытой | `test_partial_coverage_is_reported…` |

**Первая редакция теста про издержки была украшением.** Она проверяла поля `cost_usd` /
`net_pnl_usd` строки истории — и прошла при мутации, снявшей списание с `equity`: поля считаются
отдельно от кривой, поэтому отчёт оставался верным, а книга не платила. Тест переписан на замер
САМОЙ кривой (`state["equity"] < seed`), и только после этого мутация краснеет.

## Инвариант #16

Три существующих теста изменены НАМЕРЕННО, обоснование в теле каждого: фикстуры `_rows` /
`_write_ranking` теперь объявляют провенанс явно. Это ужесточение, а не ослабление — строка без
провенанса в новом контракте отбрасывается, и фикстура обязана сказать, что наблюдение было.
Запись в `docs/journal/2026-W37.md`.
