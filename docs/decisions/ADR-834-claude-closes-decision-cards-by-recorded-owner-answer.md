# ADR-834 · Карточки решений закрывает Claude — по ЗАПИСАННОМУ ответу владельца

- **Статус:** Accepted
- **Дата:** 2026-10-27
- **Решение владельца** (сессия Claude Code, 27.10): «я не хочу сам закрывать карточки руками, я хочу чтобы это делал Claude сам».
- **Меняет:** формулировку инварианта #14 (CLAUDE.md). Текст правит владелец — сессия свои инструкции не редактирует.

## Решение

1. Когда владелец ответил на вопрос — кнопкой в боте или в сессии Claude Code, — карточку решения в
   `owner-done` переводит агент. Владельцу не нужно закрывать карточки руками.
2. Граница прежняя по смыслу: **ответ не придумывается**. Ответ из сессии сначала записывается в ADR,
   который называет карточку по имени; только по такой записи `owner_answer.record_session_answer`
   закрывает карточку (поле `owner_answer_via: claude-code-session`, ссылка на ADR, честная приписка
   «закрыл агент по записи»). Нет записи — отказ, файл не тронут.
3. `owner-accepted` («принято — беру в работу») по-прежнему ставит только сам владелец.
4. Предметы ADR-285 (деньги, публичные числа, необратимое) не меняются: агент закрывает карточку ПО
   ответу владельца, а не решает вместо него.
