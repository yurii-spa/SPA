# ADR-152 · Зеркало origin для локальных сессий

- **Дата:** 2026-08-27
- **Статус:** Принято
- **Автор:** интерактивная сессия по дизайну владельца (27.08)
- **Связано:** ADR-125 (старт трёх пакетов) · правило доставки §2/§4 · инвариант #17

## Проблема

Локальные сессии рассуждают по **устаревшим** `docs/`. Замерено 27.08: сессия честно
доложила владельцу «последний ADR — 078», тогда как на origin их **129** — включая
ADR-125 о старте Balanced и Aggressive, о котором владелец и спрашивал.

Сессия не проглядела и не соврала: у неё **физически не было файла**. Индекс рабочего
дерева отставал на **1139** коммитов.

## Почему отставание штатно

Пуши уходят в origin **напрямую через API** и локального индекса не касаются. Синхронизация
(`code_sync_from_origin.sh`) возит только `spa_core/`, `scripts/`, `tests/`, `architecture/`.
`docs/` и `nimbalyst-local/` не возятся **никогда** — и не должны: они пишутся локально,
любой merge затёр бы незапушенное.

То есть отставание индекса — свойство рабочего процесса, а не поломка.

## Отвергнутое решение

**Синхронизировать рабочее дерево** (совет, прозвучавший при разборе). Отвергнуто дважды:

1. **Опасно.** `git pull` на прод-дереве прерывается 171 локальным изменением, а
   `git checkout -- data/` стёр бы живой трек (правило доставки §4).
2. **Не решило бы задачу.** Синк не возит `docs/`, так что ADR всё равно не появились бы.
   Проверено на месте: файлы пакетов `data/hy_paper_trading.json` и `lp_paper_trading.json`
   **уже были локально и свежими** — код `hy_cycle`/`lp_cycle` работает и пишет их каждый
   цикл. «После синка появятся файлы» не сработало бы: они не появились бы, они уже на месте.

## Решение

1. **Read-only зеркало** `~/Documents/SPA_mirror`: `git fetch && git reset --hard origin/main`.
   Рабочее дерево не трогается вовсе.
2. **Обновление — шагом существующего получасового агента** `system_briefing`, не новым
   launchd: плодить флот ради `git fetch` не нужно. Отказ зеркала не роняет брифинг.
3. **SessionStart-хук** предупреждает сессию об отставании при старте — раньше, чем она
   начнёт рассуждать.
4. **Строка в `SYSTEM_BRIEFING`** — отставание видно постоянно, не только при старте.
5. **Приписка в §1 `CLAUDE.md`** — источники §1 на Маке читать из зеркала.

## Границы

Зеркало **только для чтения**. Писать в него, пушить из него или запускать из него агентов
запрещено: единственный источник исполнения — рабочее дерево.

## Проверка

`test_briefing_git_index_lag.py`, 6 тестов, включая положительные контроли: отсутствие
зеркала названо отсутствием; неизмеримое отставание — «НЕ ИЗМЕРЕНО», а не ноль (инвариант
#17); число берётся из git, а не из литерала.
