# ADR-061 · Гейт доказанности APY + advisory/GSM-гейт в money-path аллокаторе (D1–D4)

- **Статус:** Proposed — реализовано и протестировано в изоляции, **ждёт go владельца на пуш**
- **Дата:** 2026-08-02
- **Автор:** сессия W4 (money-path)
- **Реализует:** L0 из ADR-060 (владелец принял дизайн и порядок «сначала честные числа»).
  **Не меняет** пороги RiskPolicy v1.0 — `spa_core/risk/policy.py` byte-identical.
- **Карточки:** `agent-apy-evidence-provenance.md` (D1/D2), `agent-book-violations-advisory-and-sky.md` (D3/D4)

## Контекст

Замер 2026-08-02: из $80 000 развёрнутых **только $20 000 ранжированы по наблюдённому числу**.
Остальное — литералы, которые система принимала за живые данные (полный разбор — ADR-060 §1):

- **D1:** 12 адаптеров читают `data/adapter_status.json` по устаревшей схеме (верхний уровень вместо
  `adapters`) ⇒ отдают зашитый `DEFAULT_APY_PCT`, а WS1.1-провайдер штампует его `apy_source="live"`.
- **D2:** `morpho_steakhouse` (40 % книги) отсутствует в `ADAPTER_REGISTRY` ⇒ вечный литерал 6.5 %
  при наблюдаемых **3.4657 %**, которые лежали непрочитанными в том же `adapter_status.json`.
- **D3:** advisory-адаптеры (`IS_ADVISORY`) исключались на live-пути, но **не** на registry-пути ⇒
  `susde` + `extra_finance_base` держали 15 % книги (нарушение инварианта 9).
- **D4:** `spark_susds.is_gsm_compliant()` = False (инвариант 10, Sky/sUSDS = 0 % до подтверждения
  GSM Pause Delay ≥ 48 ч), но 5 % книги было в нём — гейт адаптера никто не спрашивал.

## Решение

В `spa_core/allocator/allocator.py` (единственный money-path аллокатор):

1. **Доказательство = наблюдение, а не литерал.** Новая `_load_evidenced_apy()` собирает
   `{протокол: (apy, источник)}` только из двух поверхностей, несущих явный признак наблюдения:
   `adapter_orchestrator_status.json` с `live_data: true` и `adapter_status.json →
   adapters[*].live_apy is not null`. Реестровый `fallback_apy` и вызов `get_yield_info()`
   доказательством **не являются** (пока жив D1, вызов адаптера ничего не доказывает).
   Значения вне живой полосы (`0 < apy ≤ 200 %`) отбрасываются — fail-CLOSED.
2. **Неподтверждённый протокол не берётся в свежую аллокацию** (правило
   `.claude/rules/risk-engine.md`: «stale-фид ⇒ протокол не берётся»). Удержание существующей
   позиции этим ADR не запрещается — выход происходит через обычную целевую раскладку.
3. **Advisory — никогда, обоими путями.** `IS_ADVISORY` / `RESEARCH_ONLY` проверяются в одном месте
   для обеих веток загрузки (зеркало live-пути).
4. **GSM-гейт адаптера соблюдается.** `is_gsm_compliant() == False` ⇒ протокол не финансируется
   (инвариант 10 для Sky/sUSDS; `fluid_fusdc` объявляет тот же гейт намеренно).
   **Осознанно НЕ гейтим по общему `is_eligible()`**, хотя карточка это предлагала: для большинства
   адаптеров `is_eligible = gsm ∧ MIN_APY ≤ apy ≤ MAX_APY`, а эти полосы — per-adapter проверка
   вменяемости фида (spark 4–9 %, fluid 3–10 %), **не** политика (RiskPolicy: 1–30 %). Гейт по ней
   молча установил бы APY-floor, которого нет ни в одном ADR. Первая версия правки гейтила по
   `is_eligible`, и существующий тест `test_live_apy_drives_ranking_not_the_stale_literal`
   это поймал — тест не ослаблялся, изменён был код (правило 16).
5. **Fail-safe против обвала в кэш.** Меньше `_EVIDENCE_MIN_COVERAGE = 3` доказанных APY ⇒ источник
   наблюдений сломан, а не мир нефинансируем: гейт **не** применяется, ранжирование идёт по легаси-
   вселенной с громкой записью в notes. Обнуление книги из-за нечитаемого файла само было бы
   money-path инцидентом. Класс-гейт (advisory/GSM) при этом безусловен.
6. **Каждый отказ назван.** `AllocationResult.blocked_protocols` (протокол → `advisory` /
   `gsm_not_confirmed` / `gsm_gate_error` / `unevidenced`), `evidence_gate_applied`, плюс строка в
   `notes` каждого цикла и в `feed_coverage`. Молчаливых пропусков нет.
7. **Расхождение фидов (D6)** решается детерминированно: побеждает более свежий производитель
   (по `generated_at`), расхождение логируется с обоими числами.

Контракт для тестов: явно переданный `live_apy_provider` **является** картой доказательств (набор
офлайн и детерминирован); под pytest файловый источник по умолчанию не читается — тест никогда не
ранжирует на живом `data/` репозитория.

## Последствия

- **(+)** Капитал больше не ранжируется по вписанным руками числам; доля книги на наблюдаемых
  значениях 25 % → 100 %.
- **(+)** Два действующих нарушения инвариантов закрыты кодом, а не пометкой.
- **(+)** Кэш 20 % → 5 %: часть «немотивированного простоя» была следствием среза T3-капа над
  advisory-позициями.
- **(−)** Разовый оборот при переходе ≈ $27.5k (27.5 % капитала) одним циклом: бюджет оборота из
  ADR-060 (≤ 15 % за ход) ещё не реализован, поэтому переход не разбивается на шаги. Для paper
  издержек нет; до реальных денег бюджет оборота обязателен.
- **(−)** Вселенная финансирования сузилась до ~12 протоколов. Это честное следствие: остальные
  никто не наблюдает. Расширять её надо починкой фидов (D1, отдельная карточка), а не ослаблением
  гейта.
- **(−)** `fluid_fusdc` (наблюдаемые 4.67 %) заблокирован своим же GSM-гейтом, а поле `gsm_hours`
  **не производится ни одним агентом** ⇒ гейт не может быть пройден в принципе. Fail-CLOSED
  соблюдён, но это «вечный замок» — вынесено отдельной карточкой на решение владельца.

## Тесты

`spa_core/tests/test_allocator_evidence_gate.py` — 14 тестов: литерал не доказательство ·
`live_data:false` не доказательство · вне полосы → fail-CLOSED · более свежий производитель
выигрывает · нечитаемый источник не роняет · advisory не финансируется · GSM-гейт соблюдён ·
APY-полоса адаптера НЕ является гейтом финансирования · ошибка гейта → fail-CLOSED ·
неподтверждённый пул не получает капитал · morpho ранжируется по 3.4657, не 6.5 ·
при сломанном источнике книга не обнуляется · каждый отказ назван в notes.
**Верификация (честно, с оговоркой).** Прицельный прогон всей затронутой области — 74 файла
(аллокатор, policy/risk-policy, все адаптеры, cycle_runner, ребалансеры, фиды), детерминированный
порядок, сеть заблокирована плагином: **3344 passed · 325 skipped · 0 failed** (50 с).
`pre_cutover_gate` — 16/16 защит, inert. Первый полный прогон набора дал 1756 passed / 1 failed —
единственное падение (`test_live_apy_drives_ranking_not_the_stale_literal`) устранено сужением
гейта, тест не менялся.

**Оговорка:** полный `spa_core/tests/` на этой машине сейчас НЕ доходит до конца — часть тестов
ходит в живую сеть (Telegram, аналитика tier-B) и виснет. **Контрольный прогон на чистом
`origin/main` в отдельном worktree даёт тот же зависон** ⇒ дефект пред-существующий, не регрессия
этого изменения. Карточка: `agent-tests-do-live-network-io.md` (high).
