# ADR-880 — STUDIO-AUTONOMY-01: S1 принят ARB как завершённый инженерный этап; production release не разрешён

**Статус:** Accepted (решение ARB, 2026-10-31) · **Владелец решения:** ARB / владелец (Юрий) · **Связано:** ADR-857 (S1).

## Решение

S1 программы STUDIO-AUTONOMY-01 (цель → граф → допуск → действие на стенде → машинный исход; E1–E3) принят как
завершённый инженерный этап на ветке `autonomy/s1`.

| | |
|---|---|
| Принятый SHA | `a172b79d4de6cf45c78bc1118009518995720381` (ветка `autonomy/s1`; SHA не изменяется этим ADR) |
| CI | ci-control `41205228032` — 12/12 шардов, `not_obtained = 0`, `collect_errors = 0`, `error = 0`; failed 68 — те же имена, что у базы `fe77594cb` (`40933693952`), новых 0, исчезнувших 0 |
| Целевые проверки | S1 owner/goal 83/83, CI-ISOLATION-01 1082/1082, CI-PROCESS-01 13/13 (на Linux); сторож записи не называет ни одного из девяти модулей ни в одном из 12 логов шардов |
| Доказательства | `~/Documents/SPA_worktrees/arb_r8_evidence_2026-10-31/` (отчёт CI, происхождение незакоммиченных `data/`, диагностика процессов, сравнение AST-таймаутов) |

## Что это решение НЕ означает

- **Production release не разрешён.** Ни слияния в `main`, ни доставки, ни активации; реальный капитал $0.
- **Общий CI не объявляется зелёным.** 68 падений базы — отдельный известный долг и ограничение для последующего
  release gate; они не исправлялись в S1 и не скрываются.
- **AST-таймаут не считается исправленным.** `test_acceptance_probe_writer` (и, в отдельных прогонах,
  `test_list_identity_census`) упираются в порог 180 с; локальный сравнительный замер базы и кандидата одинаков,
  причина разброса в CI не установлена; порог не поднимался.

## Состав принятого S1 (по раундам ARB)

R1/R2 (общий протокол записи карточки, изоляция испытательной копии), R3/R3b/S1-R5-01/02/S1-R6-01 (ответ кнопкой
привязан к неизменному снимку показанного вопроса; журнал отправок не сокращается; неизмеренная версия не даёт
полномочий ни одной дверью), CI-ISOLATION-01 (девять тест-модулей пишут журналы в сцену теста), CI-PROCESS-01
(проба окна мутаций собирает группу процессов своей сцены до уборки). Матрица требований — ADR-857 на ветке S1.

## Записано

В ветке S2 (`s2/release-materialise`), т. к. принятый SHA S1 не должен меняться; ветка S1 не тронута.
