# ADR-875 — Сторож «офис НЕ ИЗМЕРЕН» обойдён git-tracked артефактом: 140 ложных находок из любого worktree

- **Статус:** ACCEPTED
- **Дата:** 2026-10-31 (цикл #993)
- **Класс:** метка «живое» на КОНСТАНТЕ (дословно ADR-126), рецидив аварии #207
- **Предмет границы ADR-285:** НЕТ ни одного из трёх (советующий прибор шага 0-офис)
- **Приёмка:** проба `office_absence_guard_not_fooled_by_tracked`

## Как находка пришла

Из **обязательного шага 1 приказа**, а не из поиска. `python3
scripts/consume_office_reports.py`, исполненный из изолированного worktree —
того дерева, которое требует §3.4 протокола, — ответил:

```
— итог: прочитано 3, не прочитано 140. Красные строки выше = действовать (карточки), это не декорация. —
```

Тот же прибор на том же коммите с `--data-dir <прод>/data`: **«прочитано 143,
не прочитано 0», код 0**. Прод-офис ЖИВ. Значит 140 строк «❌ НЕ ПРОЧИТАН» —
ложные находки, и приказ требует завести по ним карточки.

## Замер ДО правки

Свежий worktree от `origin/main` `39f2308c3`:

| ось | число |
|---|---:|
| целей офиса (`consumers: orchestrator_protocol`) | 143 |
| из них под `data/` | 142 |
| ЕСТЬ в дереве | **2** |
| из этих двух **git-tracked и равны HEAD** | **2 из 2** |
| печатаются находкой | **140** |
| прод тем же прибором | прочитано **143**, не прочитано **0** |

Присутствующие — `data/uptime_status.json` и `data/site_freshness_report.json`.

## Почему сторож не сработал

Класс УЖЕ закрывали: цикл #207 завёл `_office_absent_wholesale`, и её
собственный docstring описывает ровно эту аварию на двадцати артефактах.
Признак был **всё-или-ничего**:

```python
present = [t for t in data_targets if os.path.exists(...)]
if present:
    return None          # «хоть один есть ⇒ дерево производящее»
```

`CLAUDE.md` объявляет `data/` как «runtime-only в .gitignore, **часть
owner-gated tracked**», и вторая половина фразы и была дырой: git-tracked
артефакт лежит в ЛЮБОМ worktree **по построению** — его выложил `git
checkout`, а не написал флот. **Присутствие файла наблюдением не является.**
Константа читалась как доказательство живого писателя и ОТКРЫВАЛА путь
ложным находкам — дословный класс ADR-126, только зеркально: там литерал
уезжал со штампом `live`, здесь штамп `live` ставит сам сторож.

## Почему батарея этого не видела

Обратный контроль `test_missing_artifact_among_present_siblings_is_STILL_named`
создаёт присутствующих соседей `write_text` в `tmp_path`. Такой сосед
**никогда** не git-tracked — он всегда настоящая запись. Сцены, где
единственный присутствующий артефакт есть вывезенная git-ом КОНСТАНТА, в
батарее не было вовсе, а в жизни это ЕДИНСТВЕННАЯ форма worktree. Тест
проверял верное намерение на том входе, которого не бывает.

## Решение

Признак — **доказательство ПИСАТЕЛЯ** (`_writer_evidence`), а не существование
пути:

| происхождение | значение | читается как |
|---|---|---|
| untracked | `_WRITER_YES` | его писал кто-то |
| tracked и РАСХОДИТСЯ с HEAD | `_WRITER_YES` | флот перезаписал ⇒ наблюдение |
| tracked и равен HEAD | `_WRITER_CONST` | вывез `git checkout` ⇒ константа |
| git не ответил | `_WRITER_UNMEASURED` | НЕ ИЗВЕСТНО |

Хоть один СВИДЕТЕЛЬ ⇒ дерево производящее, пропажа соседа печатается находкой
как прежде. Ни одного ⇒ «⚠️ ОФИС НЕ ИЗМЕРЕН» (код 3), и присутствующие
константы **называются поимённо** — вердикт «ни один не несёт доказательства
писателя» не вправе противоречить `ls`, иначе читается как поломка прибора.

**Три исхода различимы значением (инв. #17)**, и направление умолчания
объявлено: неответ git трактуется как ПИСАТЕЛЬ — fail-CLOSED **в сторону
шума**. Обратное умолчание заставило бы сторожа срабатывать на дереве, про
которое ничего не известно, и ГЛОТАТЬ настоящие пропажи: ложная тишина тише
ложной находки и потому опаснее исходной аварии.

Спрашивается ДВУМЯ пакетными зовами git (`ls-files`, `diff --name-only HEAD`),
а не зовом на файл: целей 142, и 142 процесса превратили бы советующий шаг в
минутную паузу. `_git_lines` различает пустой успех (`[]`) и неответ (`None`) —
свести их значило бы выдать «про отслеживание неизвестно» за «ничего не
отслеживается», тот же fail-OPEN с другой стороны.

## Исход — ЗАМЕР

| | до | после |
|---|---:|---:|
| ложных «НЕ ПРОЧИТАН» из worktree | **140** | **0** |
| код возврата из worktree | 0 («всё хорошо») | **3** (НЕ ИЗМЕРЕНО) |
| присутствующие константы НАЗВАНЫ | нет | **да, поимённо** |
| прод (`--data-dir`) | прочитано 143 / 0 | **не изменился** |

## Приёмка

- Предмет: **6 passed** (новые сцены; шестая дописана по выжившему мутанту) · батарея шага ЦЕЛИКОМ **212 passed** до шестой сцены (**213** собирается после)
  (перемерена доставляющей сессией четырьмя группами: 72 + 72 + 4×17; полный
  файл идёт ~12 мин, потому что 15 его сцен поднимают настоящий `main()` на
  одноразовом дереве по ~45 с) · проба **9 passed** в 178 с (зелёная на
  контуре, красная на 4 порванных звеньях, 3 отказа с названной причиной, не
  проходит подстрокой) · проба приёмки карточки
  `office_absence_guard_not_fooled_by_tracked` = **satisfied** на доставляемых
  байтах.
- **Контроль A на чистом `origin/main` 39f2308c3** (код origin + новые тесты):
  **3 failed / 2 passed**; положительный контроль воспроизвёл аварию дословно —
  `итог: прочитано 1, не прочитано 20` при `assert 0 == 3`. Два зелёных — это
  обратные контроли, они зелены по обе стороны намеренно (иначе правка
  покупала бы тишину ценой слепоты).
- **Мутации по дельте — 10/10, и ОДНА выжила с первого раза; это находка, а не
  формальность.** Первый прогон: применено 10 · убито **9** · ВЫЖИЛА **1** —
  «происхождение спрашивается не у того дерева, чьи артефакты читаем»
  (`tree = root` вместо `dirname(data_dir)`). Прибор назвал её «дыра покрытия»,
  и это оказалось ПРАВДОЙ, а не эквивалентностью: обе прежние сцены про
  `--data-dir` спрашивали происхождение у дерева, где ответ СОВПАДАЛ, то есть
  сцены ЧЕРЕЗ ГРАНИЦУ области у признака писателя не было вовсе. Под мутантом
  `--data-dir` на чужое дерево с tracked-константами объявил бы чужой офис
  живым — та же авария #993 с другой стороны. Дыра закрыта сценой
  `test_writer_evidence_is_asked_of_the_tree_whose_artifacts_we_read` (чужое
  дерево — репозиторий с tracked-константой, своё — НЕ репозиторий, поэтому
  ответы расходятся ПО ПОСТРОЕНИЮ, а не по случаю). **Повторный прогон РОВНО
  выжившей** (`docs/mutations/ADR-875.json` → `rerun_note`): применено 1 ·
  убито **1** · выжило **0**, и убила её именно новая сцена. Итог по населению:
  **10 из 10**. Оба прогона — в ОТДЕЛЬНОМ дереве `/private/tmp/spa_c993_mut`,
  окно прибора снято с побайтовой сверкой, дерево доставки не тронуто.

## Доставка: работу сделала ОДНА сессия, доставила ДРУГАЯ

Работу выполнила сессия `cycle-65625`; она умерла ДО пуша, и дерево
`/private/tmp/spa_c993` сутки держало готовый ADR, пробу и батарею, которых на
`origin` не было вовсе. Подняла и доставила `cycle-22834` (тот же цикл #993),
**перемерив приёмку своими руками**, а не поверив прозе сироты. Шаг 0a сироту
не называет по построению: он мерит дерево ЗАПУСКАТЕЛЯ, а дерева умершей
сессии ему не видно.

**Дефект, найденный ПРИ ПОДЪЁМЕ и сиротой не измеренный.** Пакет храповиков дал
**4 failed** против **3 failed** на чистом `origin/main` в отдельном дереве —
разность РОВНО одна и она наша: `test_injected_clock_claim` назвал
`test_office_absence_guard_probe.py` ложной претензией («в файле нет ни одного
литерального якоря времени — освобождать нечего, а пометка утверждает
обратное»). Пометка `# FROZEN-DATE-OK: injected-clock` стояла в файле, у
которого литеральных дат нет вовсе: **записка не есть инъекция**, и сторож
#477 написан ровно против неё. Снята ЗАПИСКА, а не сторож (инв. #16) — после
правки 3 failed, вклад цикла **0**. Три оставшихся красны и на чистой вершине
(`test_frozen_date_ratchet` на чужом `test_edge_carry3_vs_quiet.py` ·
`test_inbox_acceptance_ratchet` — 10 карточек `done` без критерия ·
`test_unwired_guard_modules_ratchet` — `step_time_drift.py`).

**Батарея мутационного прибора СУЖЕНА поимённо до предмета — это замер, а не
удобство,** и причина записана в самой спецификации (`battery_note`): полный
файл идёт 12 мин на прогон, то есть 11 прогонов прибора стоили бы 2 ч 45 мин.
Сужение способно дать только БОЛЬШЕ выживших, а не меньше ⇒ мера от него
строже; полный файл проверен ЦЕЛИКОМ и отдельно (212 passed).

## Чего это НЕ закрывает

- **Такт шага не изменён.** Шаг по-прежнему обязан звучать из прод-дерева либо
  с `--data-dir`; правка делает молчание ВИДИМЫМ, а не ненужным.
- **Расхождение с HEAD как доказательство писателя — признак ДОСТАТОЧНЫЙ, но
  не точный:** tracked артефакт, правленный РУКАМИ в worktree, тоже сойдёт за
  писателя. Это осознанно и в ту же сторону (шум, не тишина).
- **Сколько ещё сторожей судят по существованию пути вместо наблюдения — НЕ
  ИЗМЕРЕНО.** Население класса не спрашивалось; у числа пока нет читателя,
  и выдумывать его этот ADR не вправе.
- RiskPolicy v1.0, стоп-кран, аллокатор, живой трек `data/equity_curve_daily.json`,
  `landing/**` и обёртки агентов не тронуты ни строкой.
