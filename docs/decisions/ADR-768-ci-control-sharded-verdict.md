# ADR-768 · Контрольный прогон CI по частям — единственный источник ПОЛНОГО вердикта набора

- **Статус:** Accepted — 2026-10-16 (агентское решение в рамках ADR-763, указание ARB раунд 5 п. 1; не предмет владельца).
- **Связано:** ADR-474 (сводка, а не код возврата), ADR-763, инв. #16 и #17, карточка `inbox-imena-upavshih-testov-na-main-zhivut-tol`.

## Контекст
Замер 16.10 (API): из последних 30 запусков `SPA CI` (`ci.yml`) ни один не дал вердикта — 28 push-запусков отменены
следующим пушем (`cancel-in-progress` для push), плановый запуск 38873867566 (`9b7e6442f`) снят лимитом задачи
GitHub 6 ч на 94 % (97 F, имён нет — вывод `-q`, выгрузка отчёта не идёт при отмене). `test.yml`: плановый запуск
38877303508 остановлен `timeout-minutes: 240` после 1 626 из 2 274 файлов. Полный набор идёт 5,5–6,5 ч подряд —
в одну задачу GitHub не помещается по построению.

## Решение
Добавочный workflow `.github/workflows/ci-control.yml` (`ci.yml`/`test.yml` не тронуты, проверки не отключены, таймауты
не подняты): расписание каждые 6 ч + ручной запуск; группа `ci-control`, `cancel-in-progress: false` — пуш не
отменяет, очередь не копится. Коммит фиксируется один раз; набор = ровно команда CLAUDE.md (6 корней, `SPA_ENV=ci`,
`PYTHONHASHSEED=0`, `-p no:randomly`), собирается и делится на 12 частей по файлам детерминированно (по весам);
каждый тест пишется на диск по мере выполнения; агрегатор: объединение частей = манифест, каждая часть отчиталась,
каждый тест имеет исход — иначе **INCOMPLETE** (не зелёный). Сравнение версий — `scripts/ci_control.py compare`
(новые / прежние / не получены / исправлены; разные окружения — «НЕ СРАВНИМО»).

## Последствия
- Первый вердикт — после первого планового запуска на `main` (00:23 / 06:23 / 12:23 / 18:23 UTC; GitHub может
  запускать позже) или ручного «Run workflow» (токен агента запускать не может — 403).
- 97 падений прогона `9b7e6442f` НЕ объявляются базовыми или вызванными CI до сравнения на одинаковом окружении.
- Остаток: разбиение по файлам меняет соседство тестов в процессе; веса 657 файлов — оценка до первого прогона.
