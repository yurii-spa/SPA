## Инцидент, найденный при исполнении решения 5
`deployment_acceptance` = CRITICAL: `~/Library/LaunchAgents/com.spa.capital_shadow.plist` и
`com.spa.research_factory.plist` содержат JSON-фрагменты `{"Hour":9,"Minute":45}` / `{"Hour":9,"Minute":5}`.
**Причина — команда агента** 01.11 20:23 (`plutil -extract StartCalendarInterval json <plist>` без `-o -` пишет поверх
файла). launchd держит прежние определения в памяти (09:45 / 09:05, состояние active) — агенты работают, но при
перезагрузке/новом входе не загрузятся. Проверены все 92 plist флота: испорчены ровно эти 2. Восстановление — копия из
`launchd/` репозитория (совпадает с `origin/main` побайтно и с загруженным определением); запись в
`~/Library/LaunchAgents` автоматическим путём не разрешена — выполняет владелец. Испорченные копии сохранены.
