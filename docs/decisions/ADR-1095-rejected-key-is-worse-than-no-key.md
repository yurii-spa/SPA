# ADR-1095 — Отвергнутый ключ GitHub не имеет права быть хуже отсутствия ключа

- **Дата:** 2026-11-25
- **Цикл:** #1240
- **Статус:** ACCEPTED (доставка ждёт ключа — см. §7)
- **Предмет:** дверь чтения GitHub-API (`spa_core/monitoring/record_survival_census.github_fetch`)
- **Связано:** ADR-1093 (ключ истёк, доставка остановлена) · ADR-1094 (сторож срока спрашивает
  GitHub) · ADR-1058 (живость прогона — отдельное наблюдение) · инв. #17

## 1. Замер (живой API, мёртвый `GITHUB_PAT_SPA`, 2026-11-24/25)

| ось | МЁРТВЫЙ ключ | БЕЗ ключа |
|---|---|---|
| вердикт прогона (`/actions/runs/<id>`) | HTTP 401 | **HTTP 200** |
| список артефактов | HTTP 401 | **HTTP 200** |
| ZIP артефакта (имена падений) | HTTP 401 | HTTP 401 |

Репозиторий ПУБЛИЧНЫЙ (`CLAUDE.md`: «Репо публичное: fetch без токена»). Значит на двух
осях из трёх **отвергнутый ключ строго ХУЖЕ его отсутствия**: дверь цепляла
`Authorization` безусловно и своими руками превращала публично читаемый ответ в
«НЕ ИЗМЕРЕНО: HTTP 401».

## 2. Цена — названа заказом, а не выдумана

Заказ G1078 п. 2 (цикл #1237): «вердикт прогона #1237 ТАК И НЕ ИЗМЕРЕН — `--delta
45450462551 45473114837` ответил `НЕ ИЗМЕРЕНО: HTTP 401`… спросить его первым, а НЕ
заказывать новый». Прогон простоял «неизмеренным» сутки, хотя всё это время без ключа
читалось: `status=completed`, `conclusion=failure`, `head_sha=424d23c05`, 13 из 14 джоб
упали, артефакт `ci-control-report` (1 895 429 Б) жив и не истёк.

Ошибка шла в ОПАСНУЮ сторону: «вердикта нет» приглашает заказать НОВЫЙ прогон (≈1–1,6 ч
раннера) и потерять якорь дельты — ровно то, что ADR-1058 уже запретил для другой
причины того же «НЕ ИЗМЕРЕНО».

Это тот класс, против которого написан инв. #17: сторож ответил на СВОЙ вопрос («годен
ли мой ключ»), выдав ответ за нужный («каков вердикт прогона»).

## 3. Решение

Ключ, **отвергнутый** GitHub (`KEY_REJECTED_CODES = (401, 403)`), снимается, и чтение
повторяется ОДИН раз анонимно. Дверь ОДНА — починка в ней отдаёт наблюдение всем
четырём потребителям (`ci_control_verdict` ×3, `step_time_drift_run`,
`record_survival_census`), и `run_liveness` начинает отвечать при мёртвом ключе без
единой своей правки, потому что `fetch` у неё уже вход.

**Выбор двери ПЕЧАТАЕТСЯ** (`stderr`, чтобы не попасть в `--json` на `stdout`), и
печатается у самой двери, а не у каждого потребителя: второй копии правила не бывает.
Молча подставить анонимный ответ хуже ошибки — отзыв прав выглядел бы здоровьем.

**Три исхода различимы** (инв. #17): ответ дан ПО КЛЮЧУ (`door="by_key"`) · ответ дан
АНОНИМНО (`door="anonymous"`, `key_rejected="HTTP 401"`, путь в `anonymous_paths`) ·
НЕ ИЗМЕРЕНО — отказ, называющий ОБЕ попытки. До первого чтения `door is None`: «не
спрашивали» и «ответил ключ» — разные утверждения.

## 4. Чего это НЕ закрывает

- **Имена падений остаются неизмеримыми без ключа.** Байты артефакта анонимно отвечают
  тем же 401 (замер §1), поэтому повтора у двери байтов нет НАМЕРЕННО — он не купил бы
  ни одного наблюдения. Починка возвращает те оси, что ПУБЛИЧНЫ (живость и исход
  прогона), а не вердикт целиком.
- **Отсутствие ключа остаётся исключением.** Полный вердикт требует ZIP; менять этот
  контракт значило бы переписать его сторожей (инв. #16) — он закреплён
  `test_an_absent_token_is_unmeasured_not_green` и кодом возврата 2.
- **`404` и сетевые сбои анонимно НЕ повторяются** — они не про ключ, и повтор замазал
  бы их. Положительный контроль на это переобобщение есть (M02, M12).
- Дверь не делает ключ живым. Доставка на `origin` по-прежнему стои́т (ADR-1093).

## 5. Приёмка

`spa_core/tests/test_github_door_anonymous_fallback.py` — 14 проб, пять осей: ключ
отвергнут · три исхода различимы · чужие отказы не маскируются · выбор двери печатается ·
прежний контракт не ослаблен. Сеть инъектирована, сцена восстанавливается контекстом
(`.claude/rules/deployment.md`, § «СОСЕД ПО ПРОЦЕССУ»), поэтому пробы отвечают «цела ли
дверь», а не «что сегодня у GitHub».

**Мутационный прогон в ОТДЕЛЬНОМ дереве** (`/private/tmp/spa_c1240mut`): применено 12,
**УБИТО 12, ВЫЖИЛО 0**, байты возвращены побайтово. Среди мутантов — «повтора нет
вовсе» (прежняя дверь, 8 падений), «повтор несёт ключ» (5), «повтор на любом коде» (2),
«печати нет», «печать в stdout», «названа только анонимная попытка», «отсутствие ключа ⇒
анонимное чтение».

Потребители двери зелены: `test_ci_control_verdict_wiring.py` +
`test_record_survival_census.py` — **173 passed**. Шаг 1г (дерево названо входом):
бомб нет.
