# ADR-117 — Бот сам замечает обновление своего кода и чисто выходит под респавн launchd

- **Дата:** 2026-08-22
- **Статус:** Accepted
- **Мандат — жалоба владельца 22.08 дословно:** «Это нужно починить раз и навсегда —
  ты это уже делал кучу раз но эффекта нет» (скриншот: ответ реплаем «1» на карточку,
  бот отвечает «не понял, к какому вопросу», кнопок нет).
- **Корень:** `telegram_bot` — KeepAlive-длгожитель (правило доставки: «долгоживущий
  агент держит код с момента старта»). Реплай-привязка (20.08), кнопки, подсказки —
  всё чинилось на origin и доезжало в прод-дерево автосинком, но ЖИВОЙ процесс
  исполнял память с момента старта. Каждая починка «без эффекта» — этот класс.
  Четвёртый сторож (`agent_code_freshness`) стал НАЗЫВАТЬ протухших — но ничего
  не перезапускает; R6 self_heal перезапускает — но только ЗАВИСШЕГО (маячок).
  Протухший-но-живой бот не ловил никто.

## Решение

`CodeFreshnessSentinel` в `spa_core/telegram/bot.py`: раз в 300с полл-цикл сверяет
отпечаток зоны кода бота (`spa_core/telegram` + `spa_core/owner_queue`: путь,
mtime_ns, размер каждого .py) с отпечатком на старте. Код сменился и **устоялся**
(два замера подряд один и тот же новый отпечаток — защита от полусинхронизированного
дерева) → чистый выход МЕЖДУ поллами (ни один update не брошен, лок отпущен) →
launchd KeepAlive немедленно поднимает бота уже с новым кодом.

Fail-safe в обе стороны: отпечаток не измерился (нет зоны, IO-ошибка) — живём
дальше, сомнение не роняет живого бота; флаппинг отпечатка (доставка идёт прямо
сейчас) — выхода нет, ждём устояния. Второй поллер не возникает по построению:
это выход-и-респавн той же launchd-job, не второй запуск (класс 409 закрыт).

## Приёмка

`spa_core/tests/test_bot_code_freshness_exit.py`: неизменный код никогда не
выходит · изменение+устояние = выход вторым замером · флаппинг не выходит ·
откат сбрасывает фазу · пустая зона fail-safe · такт дешёвый · отпечаток видит
новый файл. 3 мутации краснят (снята двухфазность / снято сравнение со стартом /
опустела зона). Смежные 493 passed.

## Доставка

Ирония класса учтена: ЭТА починка — последняя, которой нужен ручной перезапуск
бота (`launchctl kickstart -k gui/$(id -u)/com.spa.telegram_bot`), дальше все
будущие доезжают сами в пределах ~10 минут после автосинка.
