# ADR-072 · Срезанный гейтом бюджет не выбрасывается: перераздача под повторным гейтом

- **Статус:** Accepted (мандат владельца 2026-08-07: «кэш без дела — срочно поменять»)
- **Дата:** 2026-08-07
- **Автор/утвердил:** автопилот-сессия (Claude) / владелец

## Контекст

Замер 07.08: кэш 25% при обязательном буфере 5%. Диагноз до строки кода: оптимизатор
(optimized_yield) раздаёт 95% капитала; защитные тримы RiskPolicy-гейта (below-median
ADR-055, TVL-freeze ADR-053) срезают веса (maple 20→10%, morpho 20→5%) — и срезанные
~20% ПРОСТО ВЫБРАСЫВАЛИСЬ в кэш под 0%, хотя рядом стояли live-кандидаты с положительной
доходностью и свободными потолками (compound_v3 T1 3.3% $37.6M — с нулём). Для
простаивающего кэша планка сравнения — 0%, а не лучшая позиция книги. Параллельный
контур причину НАЗВАЛ (capital-efficiency LAZY 10%, ~50 bps/год) и честно оставил
money-path решение владельцу; владелец решил.

## Решение

`redistribute_freed_budget` (spa_core/paper_trading/risk_gate.py, рядом с гейтом) +
один вызов в cycle_runner ПОСЛЕ гейта:

1. **Перераздаётся строго срезанное гейтом**: `min(буфер-предел − размещено,
   заявлено_аллокатором − размещено)`. Недобор самой модели (маленькая книга по её
   решению) НЕ заполняется — спасаем срезанное, не отменяем модель.
2. **Кандидаты** — только `tvl_source=="live"` и конечный APY > 0 из того же снимка,
   что видит гейт (литералы не годятся, ADR-061/063); ранжирование по APY вниз.
3. **Слово гейта свято**: пулы, которые гейт срезал или заморозил, капитал НЕ получают;
   потолки T1 40 / T2 20 / T2-total 35 / ALLOC-002 соблюдаются в функции И новый target
   ОБЯЗАТЕЛЬНО проходит гейт ПОВТОРНО — отказ второго прохода отменяет перераздачу
   целиком (инвариант 1: RiskPolicy — единственный hard-гейт, последнее слово его).
4. Каждое размещение — именованная строка (ADR-055 provenance); отказ функции
   fail-open к прежнему поведению (кэш остаётся, цикл живёт).

**Пороги RiskPolicy v1.0 не изменены ни на бит.**

## Последствия

- Ожидание на сегодняшнем срезе: кэш 25% → ~5–10% (буфер + подлинно cap-bound остаток);
  смесь ~5.8% → ~6.5%+ на весь капитал; «LAZY 10%» из системного WARN гаснет честно.
- 9 тестов (positive control = инцидент 07.08; слово гейта; не-live не кандидат; буфер;
  потолки; ALLOC-002; недобор модели не трогаем; мелочь; мусор). Money-path свип:
  1784 passed (единственный красный — до-ADR-065 GSM-тест, существует на чистом origin,
  карточка заведена); pre_cutover_gate 17/17 PASS.
- Trade-off честно: перераздача добавляет оборот в день больших тримов; анти-churn
  контуры (ADR-060 SHADOW, недельный бюджет) на неё не распространяются — это не
  ребаланс по сигналу, а не-выбрасывание уже одобренного бюджета.
