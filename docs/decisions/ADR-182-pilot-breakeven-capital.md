## 1. Перепроверка чисел поправки ADR-168 (переиграно заново, не переписано)

Та же неделя (22 перекладки, окно 2026-08-22T15:42 … 2026-08-29T15:42) переиграна через
доставленный `churn_damper.decide()` — каждая сделка предъявлена с журналом, каким он был бы
в мире с ограничителем. Форма совпала с поправкой, доллары — не совсем:

| | поправка ADR-168 | этот замер | расхождение |
|---|---|---|---|
| ходов прошло | 3 (2 де-риска + 1 дискр.) | **3 (2 де-риска + 1 дискр.)** | нет |
| причины отказов | min_hold 16 · budget 3 | **min_hold 16 · budget 3** | нет |
| односторонний оборот | $47 895 | **$47 895** | нет |

Расхождения — из модели ног: этот замер считает газ по КАЖДОЙ тронутой позиции с цепочкой
из `adapter_registry.json` (дискреционный ход 25.08 тронул 2 ethereum-ноги ⇒ $24 газа, а не
~$12) и добавляет мост 5 бп на мультичейн-де-риске 29.08. Заработок $87 в ADR-168 занижен —
сумма `daily_yield_usd` по окну даёт $112.22; вывод ADR-168 от этого НЕ меняется:
**издержки ($124.81) всё ещё больше заработка ($112.22)**, и дискреционная часть ($28) уже
не главная — $96.81 стоят два хода де-риска, которые задерживать нельзя.

Доходность книги для расчёта ниже: 30 evidenced-дней equity-кривой, $15.65/день на $100 000
= **5.71 % годовых** (до вычета издержек; paper-трек издержки не платит).

### 1-бис. Код уехал под сессией: замер на сегодняшнем коде и окне

Пока считалась эта задача, origin принял **ADR-181** (решение владельца 30.08): размещение
простаивающего кэша не задерживается выдержкой (бюджет оборота остаётся). Реплей той же
методикой на коде HEAD и сегодняшнем окне (23 сделки по 30.08T20:46) даёт **5 ходов /
$209.62/нед** против заработка **$110.47**: к трём ходам выше добавились два освобождённых
размещения ($84.81). Из них одно — **вторая нога маятника 27.08**: продажа $14 211 в 15:41
(де-риск, не задерживается) и откуп ТЕХ ЖЕ $14 211 в 16:26 прошли бы как «размещение».
Тест ADR-181 закрыл эту дырку для ПУСТОЙ книги; для частичного де-риска она открыта — бюджет
оборота её ограничивает, но не закрывает. Это замер, не спор с решением владельца; класс
назван карточкой `inbox-vtoraya-noga-mayatnika-prohodit-kak-razmeschenie`. Для расчёта ниже
взят профиль недели ADR-168 (без размещений): размещения — переходный режим после починки
ADR-171, их годовую частоту мерить пока не на чем.

## 2. Главная находка: у нас НЕТ измеренной цены газа НИ ДЛЯ ОДНОЙ сети

Проверено 30.08 запуском мониторов и прямым опросом их источников:

- `unified_gas_monitor` (Ethereum): «fallback constant, no network call» — 20 Gwei, ETH $3200.
  Известно из `cost_model_provenance.md`, подтверждено.
- `arbitrum_gas_monitor --check` напечатал 0.1 Gwei, `optimism_gas_monitor --check` — 0.05 Gwei.
  Это **ровно их FALLBACK_GWEI**: Blocknative отвечает пустым телом, Infura требует ключ.

## 3. Структура издержек: что лечится капиталом, а что — нет

Издержки = **фиксированная** часть (газ: $/ногу × ног/нед, от капитала не зависит) +
**пропорциональная** (слиппедж 8 бп + мост 5 бп от оборота — растёт вместе с капиталом).
Отсюда два разных вывода:

1. Безубыточность по капиталу существует только против газа.
2. Пропорциональная часть задаёт **потолок достижимого покрытия**: при измеренном недельном
   профиле (оборот 47.9 % капитала, из них 43 % — де-риск) слиппедж съедает
   52 × 0.479 × 8 бп ≈ **1.99 %/год** при доходности 5.71 % — покрытие лучше ~2.9× недостижимо
   НИ НА КАКОЙ сети и ни при каком капитале. Единственный рычаг — оборот де-риска, который
   частотой не ограничивается (и не должен).

## 4. Точка безубыточности по капиталу (годовой заработок ≥ k × годовые издержки)

Профиль А — измеренная неделя с де-риском (7 ног, оборот 47.9 %/нед); профиль Б — тихая
неделя (1 дискреционный ход, 2 ноги, 5 %/нед). Расчёт — `pilot_breakeven.py`, закреплён
`test_pilot_breakeven.py`.

| Сеть · цена газа | А, k=1 | А, k=2 | Б, k=1 | Б, k=5 |
|---|---|---|---|---|
| mainnet @ 20 Gwei (константа) | **$122 тыс.** | **$526 тыс.** | $23.5 тыс. | $139 тыс. |
| mainnet @ спот 30.08 | $443 | $1 908 | $85 | $503 |
| arbitrum / optimism @ конст. $0.25 | $2 448 | $10 552 | $473 | $2 784 |
| base @ конст. $0.15 | $1 469 | $6 331 | — | — |
| polygon | НЕ ИЗМЕРЕНО (конст. $0.05 без даты и источника) | | | |

**Предлагаемый запас — k=2 по профилю А** (заработок ≥ 2× издержек в де-риск-тяжёлую неделю).
Обоснование: (а) измеренный разброс профилей А/Б — ~2.5× по стоимости; (б) доходность книги
падает (эпизод 4.21 → 3.18 % за сутки, W35); (в) слиппедж 8 бп не проверен на размере.
Требовать k=5 по профилю А бессмысленно — недостижимо структурно (§3).

Итого: **книга $100 тыс. на mainnet ниже безубытка при константах модели ($122 тыс.) и
глубоко выше него при спот-газе ($443)**. Вердикт о mainnet целиком держится на числе,
которого у нас нет. Для L2 вердикт устойчив: безубыток — единицы тысяч долларов при ЛЮБОЙ
правдоподобной цене газа.

## 5. Минимальный осмысленный размер позиции (окупаемость ≤ 45 дн, колонка «пилот» ADR-060)

Ход из 2 ног, выгода Δ = 1 пп годовых на позицию:

| Сеть · газ | минимум при 1 пп | при 2 пп |
|---|---|---|
| mainnet @ 20 Gwei | **$57.5 тыс.** | $15.0 тыс. |
| mainnet @ спот | $209 | $54 |
| arbitrum @ конст. $0.25 | **$1 155** | $300 |
| base @ конст. $0.15 | **$693** | $180 |
| любая сеть, кросс-чейн ход | **НИКОГДА** (мост 5+8=13 бп > 12.3 бп выгоды за 45 дн) | $429 |

Owner-директива «~1000 USDT на стратегию»: на mainnet при константах модели такой размер
**не окупает ни одного хода никогда** (подтверждает ADR-060 §3 «905 дней»); на Arbitrum при
1 пп — на грани ($1 155 > $1 000), на Base проходит ($693). Кросс-чейн ходы для пилота мертвы
при любом размере — пилот обязан жить одноцепочечно, мост — только разовый вход/выход.

## Честный остаток

- Цена газа Ethereum как РАСПРЕДЕЛЕНИЕ не измерена; спот 30.08 — одна точка. Любое решение
  «пилот на mainnet» до появления живого фида с историей — решение на неизмеренном числе.
- Слиппедж 8 бп — константа без размера ордера; на $1 000 и на $40 000 это разные утверждения.
- Профиль А — одна неделя; частота недель с де-риском не измерена (двух недель с ограничителем
  ещё не прожито).
- Доходность 5.71 % — тренд вниз; безубыток при 4 % и профиле А на mainnet @ 20 Gwei — уже
  ~$220 тыс., растёт быстрее чем линейно (знаменатель худеет с двух сторон).
