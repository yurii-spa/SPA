## Что строим — одной рамкой

Внешняя рамка взята из книги Р. Гамзатова «Бизнес, понятный машинам» (AI1), она лежит
в `~/Downloads/Бизнес_понятный_машинам_AI1_пособие_docx.pdf` (61 стр., текст извлекается
`pdftotext`, poppler установлен 27.08).

Лестница зрелости оттуда: задача → агент → данные → инструменты → связка → **контракт** →
оркестратор → контроль → межфункциональная система → операционный слой.

**Диагноз (ADR-154): у нас оркестратор построен раньше контрактов** — седьмая ступень при
пропущенной шестой. Поэтому все отказы происходят на стыках.

## Действующий план — [ADR-154](decisions/ADR-154-contracts-before-orchestration.md)

Порядок не произволен, каждый пункт даёт вход следующему. Полный текст с деталями —
карточка `agent-roadmap-adr154-contracts`.

1. **Паспорт агента обязателен.** Модуль `spa_core/monitoring/agent_passport.py` готов,
   три состояния (full/partial/missing). Замер: из 95 агентов полный паспорт у **24**.
   В гейт установки НЕ вшит — иначе 71 агент перестанет ставиться. Сначала заполнить.
2. **Минимальный пакет передачи** вместо голой карточки.
3. **Разбор отделить от исполнения** — по типу процесса, не по расписанию.
4. **Реестр периодических обязанностей** (суточный аудит идёт каждым прогоном).
5. **Инвентаризация 81 агента** — кто в потоке ценности.
6. **Дашборд — последним**, осознанно: его содержимое и есть поля паспорта.

**Отложено сознательно:** частоту оркестратора выше 15 мин не поднимать,
`MAX_CONCURRENT=2` не включать, второй оркестратор не ставить.

## Пять ловушек, на которых сессия 27.08 ошибалась

1. **Правка в `scripts/` живёт минуты** — синхронизация возит их с origin перед каждым
   прогоном. Порядок: правка и пуш ОДНОЙ командой, проверка origin ПОСЛЕ.
2. **`docs/`, `nimbalyst-local/` не синхронизируются никогда** — читать из зеркала.
3. **Приёмку и подсчёты запускать из прод-дерева**, не из worktree (`data/` там checkout).
4. **Считать карточки — только `scripts/tracker_counts.py`**, он называет источник сам.
5. **Прежде чем сказать «этого нет» — вывести все ключи и все соседние имена.**
   Пять ошибок за день: искал `tier` вместо `hy/lp`, `history` вместо `daily_history`,
   `[[wiki]]` вместо markdown-ссылок, имя файла вместо номера ADR, локальное дерево вместо origin.
