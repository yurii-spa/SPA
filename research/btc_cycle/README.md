она эти попытки пережила.

## ⚠️ Чего здесь НЕТ — и без чего ничего не запускается

Оба скрипта начинаются со строки `import backtest as v1` и берут из него ВСЁ
существенное: саму лестницу (`run_ladder`), определения фаз (`raw_regime`,
`BASE_W`), параметры (`COOLDOWN`, `CONFIRM_RISK_UP/DN`, `CRASH_7D`), сборку
сигналов (`build_signals`), симулятор (`simulate`) и метрики. Отсутствуют:

- **`backtest.py` (v0.1 — канонический чемпион)** — главная потеря;
- `btc_dataset.csv`, `m2.csv` — исходные ряды;
- `backtest-results-v01.md` — родительский документ вердикта;
- **логика загрузки данных** — вердикт сам пишет: «fetch-логика в этом чате».

Пока их нет, **числа вердикта — чужое утверждение, а не наш замер.**
Восстановить их — шаг 0 любой дальнейшей работы (`CLAUDE.md` §4: чат не
хранилище).
