# Итерации v0.2–v0.3 и финальный вердикт по бэктест-фазе

**Дата:** 20 августа 2026. Продолжение backtest-results-v01.md.

## Что проверили

**v0.2 — трендовый гейт на покупку** («дёшево И перестало падать»: доля выше 50% только при цене выше 20W SMA) + замена crash-сброса на 28-дневный запрет наращивания после недельного падения >20%.
Результат: ПРОВАЛ. Доходность −5…−9 п.п. на всех окнах, просадка почти без улучшения (−39.9% vs −43.4% на Тест-1). Диагноз: главная просадка возникает не при покупке дна, а при пересиживании середины медвежьего рынка с 35–50% BTC — гейт лечил не то место.

**v0.3 — тренд как жёсткий потолок/пол** (медвежий тренд: доля ≤35%; бычий: доля ≥55%).
Результат: ПРОВАЛ. Просадка улучшилась умеренно (−35…−38%), но доходность упала на 9–16 п.п. — потолок срезает экспозицию и в коррекциях бычьего рынка. Calmar хуже v0.1 на всех окнах, включая чистую калибровку (0.77 vs 1.06).

**Риск-бюджетное масштабирование v0.1** (вся лестница × k — линейное решение, не подгонка):
| k | Полный период CAGR / MaxDD | Тест-2 CAGR / MaxDD |
|---|---|---|
| 1.0 | 36.1% / −43.4% | 36.1% / −30.9% |
| 0.8 | 29.1% / −36.5% | 27.9% / −24.8% |
| 0.7 | 25.8% / −32.6% | 25.3% / −21.0% |
| 0.6 | 21.8% / −30.1% | 21.4% / −18.9% |

Calmar при масштабировании почти не деградирует (0.83 → 0.79 при k=0.7) — соотношение доходность/риск сохраняется, выбор k — это выбор аппетита к просадке, а не оптимизация.

## Финальный вердикт бэктест-фазы

1. **Чемпион — v0.1 без модификаций.** Обе «умные» правки уничтожали больше альфы, чем спасали просадки. Это типичный и здоровый результат: простая система пережила попытки её улучшить.
2. Просадка −40% — **свойство класса стратегии** (лестница всегда держит BTC), а не дефект реализации. Управляется линейным k без потери качества.
3. **Дальнейшие итерации правил останавливаем.** Три версии — разумный лимит; продолжение = подгонка под уже вскрытые тестовые окна.
4. Рекомендованная конфигурация для paper-трека: **v0.1 с k=0.7–0.8** → ожидание ~25–29% CAGR при MaxDD −33…−37% на уровне движка. В составе портфеля (движок ~50–60% + RWA-пол + carry) просадка на уровне общего NAV разбавляется примерно до −20…−25%.
5. Все цифры — по трём с половиной циклам истории; трактуются как «не опровергнуто». Единственная чистая валидация — живой paper-трек: тестовые окна вскрыты, любая дальнейшая настройка по ним запрещена.
